# 우르르 개인정보처리방침

우르르(이하 "서비스")는 이용자의 개인정보를 소중히 다루고, 「개인정보 보호법」과 「위치정보의 보호 및 이용 등에 관한 법률」을 지켜요. 이 방침은 서비스가 어떤 정보를 왜 모으고, 얼마나 보관하고, 어떻게 지우는지 알려 드려요.

## 1. 모으는 정보

| 언제 | 정보 | 필수 여부 |
|---|---|---|
| 로그인 | 구글 계정의 고유 번호(uid), 이메일 주소 | 필수 |
| 가입 | 아이디, 닉네임, 생년월일, 국가 | 필수 |
| 프로필 꾸미기 | 프로필 사진(최대 10장), 관심사 | 선택 |
| 서비스 이용 | 친구 관계, 좋아요, 메시지·음성 메시지, 스토리, 차단 목록 | 이용할 때 |
| 신고 | 신고한 사람·신고된 사람, 신고 이유, 설명(500자 이내), 첨부 사진 1장 | 신고할 때 |
| 안전 조치 | 위반 횟수, 경고·이용정지 기록 | 위반이 있을 때 |
| 위치 공유 | 대략적인 지역 (아래 3번) | **위치 공유를 켠 사람만** |
| 자동으로 | 기기 언어 설정, 서비스 접속·오류 기록 | 자동 |

- 비밀번호는 받지 않아요. 로그인은 **구글 계정으로만** 해요.
- 주민등록번호, 전화번호, 정확한 주소는 모으지 않아요.

## 2. 이용 목적

1. 회원 확인, 가입·탈퇴 처리, 만 19세 이상인지 확인
2. 친구 찾기, 메시지·스토리 주고받기, 친구 지도 보여주기
3. 신고 처리, 규칙 위반 확인과 이용 제한, 다시 가입해서 제재를 피하는 것 막기
4. 문의 답변, 서비스 오류 확인과 개선

## 3. 위치정보

- 위치 공유는 **"나" 탭에서 직접 켠 사람만** 해요. 켜지 않으면 위치를 전혀 쓰지 않아요.
- 휴대폰의 위치(위도·경도)는 **지역 이름을 찾을 때만** 쓰고 어디에도 저장하지 않아요.
- 친구에게 보이는 것:
  - **모든 친구**: 시·도까지 (예: "대한민국 경기도")
  - **유료 이용 친구**: 동까지 (예: "경기도 평택시 서정동")
- 정확한 주소나 좌표는 누구에게도 보여주지 않아요.
- 지역은 **앱을 쓰는 동안만** 서버에 있어요.
  - 앱을 닫거나 화면에서 내리면 바로 지워요.
  - 휴대폰이 꺼지는 등으로 바로 지우지 못하면 **10분 안에 서버가 자동으로** 지워요.
- 위치 공유는 언제든 끌 수 있고, 끄는 즉시 지워요.

## 4. 보관 기간과 파기

| 정보 | 보관 기간 |
|---|---|
| 메시지·스토리 | 보낸 지 **24시간** 뒤 자동 삭제 (직접 저장한 메시지는 대화방이 남아 있는 동안) |
| 위치 공유 지역 | 앱을 쓰는 동안만 (화면에서 내리면 바로, 늦어도 10분 안에 삭제) |
| 계정·프로필 | 회원탈퇴 뒤 **7일** 유지 후 삭제 (서비스에서 보이지 않게 됨) |
| 사진·친구 관계·좋아요 등 회원 정보 | 운영자 확인 뒤 회원탈퇴일로부터 **한 달 안에** 서버에서 완전히 삭제 |
| 신고 기록, 위반·이용정지 기록 | 회원탈퇴 뒤 **한 달** 보관 후 회원 정보와 함께 삭제 (다른 이용자 보호, 제재 회피 방지) |

- 지운 정보는 되살릴 수 없도록 서버에서 삭제해요.
- 법에서 따로 보관하라고 정한 정보는 그 기간 동안만 따로 보관해요.

## 5. 다른 곳에 주는 경우

- 이용자의 개인정보를 다른 회사나 사람에게 팔거나 넘기지 않아요.
- 법에 따라 수사기관이 정해진 절차로 요청할 때만 예외로 제공해요.

## 6. 처리를 맡기는 곳

서비스 운영을 위해 아래 회사의 서비스를 써요.

| 맡기는 곳 | 하는 일 | 정보가 있는 곳 |
|---|---|---|
| Google LLC (Firebase) | 로그인, 데이터·사진 저장, 서버 운영 | 대한민국(서울) 및 Google 데이터센터 |
| ㈜카카오 (카카오맵) | 지도 보여주기, 위치 → 지역 이름 찾기 | 대한민국 |

- 카카오에는 지역 이름을 찾을 때 위치(위도·경도)만 보내고, 이름·아이디 같은 정보는 보내지 않아요.

## 7. 이용자의 권리

1. 이용자는 언제든 자기 정보를 보고, 고치고, 지울 수 있어요.
   - 프로필·사진·관심사: "나" 탭에서 직접 수정
   - 위치 공유: "나" 탭에서 끄기
   - 회원탈퇴: "나" 탭 → 회원탈퇴
2. 앱을 쓸 수 없으면 문의 이메일로 탈퇴를 요청할 수 있어요. 본인 확인 뒤 7일 안에 처리해요.

## 8. 만 19세 미만

서비스는 **만 19세 이상**만 가입할 수 있어요. 만 19세 미만의 정보를 알게 되면 바로 지워요.

## 9. 안전하게 지키는 방법

- 서버 보안 규칙으로 본인과 허락된 친구만 정보를 볼 수 있게 막아요.
- 모든 통신은 암호화(HTTPS)해요.
- 운영자 사이트는 따로 로그인하고, 꼭 필요한 운영자만 접근해요.
