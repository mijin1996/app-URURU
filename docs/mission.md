# mission.md — 우르르는 왜 만드나

> [기본 원칙 1] 제품의 방향과 목적 (존재 이유, 가치 제안)
> 기능을 더하거나 뺄 때 "이게 미션에 맞나?"를 이 문서로 판단해요.

---

## 1. 한 줄로

**가까운 친구와 가볍게 모이는 앱.**
주변 친구가 지도에서 어디 있는지 보고, 스토리로 근황을 나누고, 24시간 뒤 사라지는 메시지로 부담 없이 대화해요.

## 2. 누구를 위한 앱인가

| 사람 | 바라는 것 |
|---|---|
| 동네 친구가 있는 10~20대 | "지금 근처에 누가 있지?"를 한눈에 보고 바로 만나기 |
| 새 친구를 사귀고 싶은 사람 | 주변 사람을 카드로 넘겨 보며 좋아요로 친구 맺기 |
| 대화 기록이 쌓이는 게 부담스러운 사람 | 메시지가 저절로 사라지고, 남기고 싶은 것만 저장 |

## 3. 가치 (이 앱만의 것)

1. **거리가 보이는 지도**: 친구 핀 아래에 "이름 · 거리"가 표시돼요.
2. **시간이 보이는 스토리**: 스토리 테두리가 24시간에 걸쳐 줄어들어서, 숫자 없이도 언제 올렸는지 느껴져요.
3. **가벼운 대화**: 메시지는 24시간 뒤 사라지고, 두 번 터치한 것만 남아요.
4. **급할 때 닿는 연락**: 친구가 허락했다면 폰이 무음이어도 "소리 울리기"가 들려요.
5. **안전**: 신고한 사람은 친구, 채팅, 지도, 스와이프 어디에도 다시 나오지 않아요.

## 4. 참고한 앱

| 앱 | 가져온 것 |
|---|---|
| Yubo | 전체 화면 디자인, 스와이프 카드 |
| Snapchat | 지도 위 친구, 스토리, 사라지는 메시지 |
| Instagram | 스토리 좋아요, 폰트 배경 상자 |

## 5. 어디서 돌아가나

**PC 브라우저 · Android · iOS 세 곳 모두**에서 같은 화면, 같은 동작이어야 해요.
화면은 폰 세로 비율을 기준으로 만들고, PC에서는 가운데에 폰 크기로 보여요.

## 6. 하지 않는 것 (지금은)

| 안 하는 것 | 이유 |
|---|---|
| 모르는 사람에게 먼저 메시지 보내기 | 좋아요를 서로 눌러 친구가 된 다음에만 대화 (안전) |
| 오래 남는 피드 / 게시글 | "가볍게"라는 미션과 맞지 않음 |
| 단체 채팅 | 1:1이 먼저. 필요해지면 roadmap에 올림 (YAGNI) |
| 정확한 주소 공유 | 동네 + 거리(km)까지만 |
