# 구글 지도 API 키 받기

> 위치: `docs/guides/google-maps-api-key-guide.md`
> 언제: 지금 받아 둬도 돼요. 다만 **키를 쓰는 코드(`add-google-map`)는 아직 안 만들었어요.** Phase 2(React) → Phase 2.5(구글 지도)가 끝나야 키를 넣었을 때 지도가 바뀌어요.

---

## 0. 미리 알아둘 것

| 항목 | 내용 |
|---|---|
| 필요한 것 | 구글 계정, **결제 수단(카드)** — 무료 사용량 안에서만 써도 결제 계정 연결은 필수 |
| 무료 사용량 | 지도 화면(Dynamic Maps) **한 달 10,000번 불러오기까지 무료** (2025년 3월부터 제품별 무료량 방식) |
| 넘으면 | 1,000번에 약 7달러 (사용량이 많을수록 단가가 내려감) |
| 우리가 쓰는 API | **Maps JavaScript API** 하나 (지도 그리기) |

> 요금은 바뀔 수 있어요. 키를 만들 때 구글 요금 페이지에서 한 번 더 확인하세요.

## 1. 프로젝트 만들기

1. https://console.cloud.google.com 에 구글 계정으로 들어가요.
2. 맨 위 프로젝트 고르는 칸 → **새 프로젝트** → 이름 `moyeo` → **만들기**
3. 만든 프로젝트가 선택됐는지 위쪽에서 확인해요.

## 2. 결제 계정 연결

1. 왼쪽 메뉴 ☰ → **결제(Billing)**
2. **결제 계정 연결** → 카드 정보 입력
3. 이 프로젝트에 연결됐는지 확인해요.

## 3. Maps JavaScript API 켜기

1. ☰ → **API 및 서비스** → **라이브러리**
2. `Maps JavaScript API` 검색 → **사용(Enable)**

## 4. API 키 만들기

1. ☰ → **API 및 서비스** → **사용자 인증 정보(Credentials)**
2. **+ 사용자 인증 정보 만들기** → **API 키**
3. 나온 키(예: `AIzaSy...`)를 복사해 둬요. **다른 사람에게 보여주지 마세요.**

## 5. 키에 제한 걸기 (꼭 하기 — 요금 폭탄 막기)

웹 지도 키는 웹 코드 안에 들어가서 누구나 볼 수 있어요. 그래서 **우리 앱에서만 쓰이게** 제한을 걸어요.

| 제한 | 설정 |
|---|---|
| **API 제한** | "키 제한" → **Maps JavaScript API만** 선택 |
| **애플리케이션 제한** | "웹사이트" → 허용할 주소 추가 |

허용할 주소 (지금 정할 수 있는 것):
- `http://localhost:5173/*` — PC에서 개발할 때
- `capacitor://localhost/*` — 아이폰 앱 안
- `https://localhost/*` — 안드로이드 앱 안 (Capacitor 기본값)
- 앱인토스·웹 주소는 정해지면 추가

> 앱인토스 안에서 지도가 안 뜨면 개발자 도구(웹 디버그 툴즈)의 오류 메시지에 나오는 주소를 여기에 추가하면 돼요.

## 6. 맵 ID 만들기 (핀을 지금 모양 그대로 쓰려고)

1. ☰ → **Google Maps Platform** → **지도 관리(Map Management)**
2. **맵 ID 만들기** → 이름 `moyeo-home`, 유형 **JavaScript**, **벡터**
3. 나온 맵 ID를 복사해 둬요.

## 7. 예산 알림 걸기

1. ☰ → **결제** → **예산 및 알림**
2. 예산 예: 월 1만 원, 50% · 90% · 100%에서 메일 알림
3. (선택) **API 및 서비스 → 할당량**에서 Maps JavaScript API 하루 사용량 상한을 낮게 걸어요.

## 8. 프로젝트에 넣기 (Phase 2.5가 끝난 뒤)

프로젝트 맨 위 폴더에 `.env` 파일을 만들고 두 줄을 적어요.

```text
VITE_GOOGLE_MAPS_API_KEY=여기에_API_키
VITE_GOOGLE_MAPS_MAP_ID=여기에_맵_ID
```

- `.env`는 zip이나 깃허브에 **올리지 않아요.** (빈 칸짜리 `.env.example`만 올려요)
- 키를 넣고 `npm run dev` → 홈에 구글 지도가 나오면 성공이에요.
- 안 나오면 배너 "지도를 불러오지 못해 기본 지도를 보여줘요"가 뜨고 그림 지도로 동작해요. 그때는 5번 제한 주소를 확인하세요.
