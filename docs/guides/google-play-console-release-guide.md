# 구글 플레이 콘솔에 안드로이드 앱 올리기

> 위치: `docs/guides/google-play-console-release-guide.md`
> 전체 순서는 `docs/guides/launch-checklist.md` C단계, 콘솔에 넣을 글·그림은 `store/google-play/`, 준수사항은 `docs/policy/compliance.md`
> 언제: **Phase 5(`add-build-targets`)까지 끝난 뒤.** 지금 버전(v13)은 웹 버전이라 아직 올릴 파일이 없어요.

---

## 0. 먼저 준비할 것

| 준비물 | 왜 |
|---|---|
| 구글 플레이 개발자 계정 (등록비 한 번 25달러) | 앱을 올리려면 필요 |
| 본인 인증 (신분증) | 계정 만들 때 구글이 확인 |
| **안드로이드 폰 또는 에뮬레이터** | 올리기 전 직접 실행 확인 |
| **테스터 12명** (개인 계정이라면) | 아래 4번: 2023년 11월 13일 이후 만든 개인 계정은 12명이 14일 동안 테스트해야 정식 출시 신청 가능 |
| 개인정보처리방침 웹 주소 | 위치·사진을 다루는 앱은 필수 |
| 앱 아이콘 512×512, 그래픽 이미지 1024×500, 휴대폰 스크린샷 2장 이상 | 스토어 화면 |
| **진짜 서버** | 실제 사람끼리 대화하려면 필요 (지금은 가짜 서버라 혼자만 보임) — Firebase (`add-real-server`) |
| **안전 장치** | 차단, 약관 동의, 웹 회원탈퇴 링크는 구글 필수 — `add-safety-basics` |
| 위치기반서비스사업 신고 확인 | 한국에서 친구에게 위치를 보여주면 대상일 수 있음 (방송통신위원회) |

## 1. 개발자 계정 만들기

1. https://play.google.com/console 접속 → 구글 계정으로 로그인
2. 계정 유형 고르기: **개인** 또는 **조직(사업자)**
3. 등록비 결제, 본인 인증, 연락처 확인

## 2. 앱 파일(AAB) 만들기 — 미미 컴퓨터에서

```bash
npm run build:android  # 구글 플레이용 웹 화면 만들기 (전체 기능, 구글 로그인)
npx cap sync android   # 안드로이드 프로젝트에 복사
npx cap open android   # Android Studio 열림
```

Android Studio에서:
1. 메뉴 **Build → Generate Signed App Bundle / APK** → **Android App Bundle** 선택
2. **서명 키(keystore) 새로 만들기** → 비밀번호 정하고 파일 저장
   - ⚠️ **이 파일과 비밀번호를 잃어버리면 앱 업데이트가 어려워져요.** USB·클라우드 두 곳에 보관하세요.
   - ⚠️ zip이나 깃허브에는 절대 넣지 마세요.
3. **release** 선택 → 완료
4. `android/app/release/app-release.aab` 파일이 생겨요. 이게 올릴 파일이에요.

> 올리기 전에 `android/app/build.gradle`의 `versionCode`(1, 2, 3 … 올릴 때마다 +1)와 `versionName`(예: `1.0.0`)을 확인하세요.

## 3. 플레이 콘솔에 앱 만들기

1. **앱 만들기** → 앱 이름 `우르르`, 기본 언어, 앱(게임 아님), 무료
2. 왼쪽 **대시보드**의 "앱 설정" 항목을 하나씩 채워요.

| 항목 | 우르르에서 적을 것 |
|---|---|
| 개인정보처리방침 | 웹 주소 |
| 앱 액세스 권한 | 가입이 필요하면 심사용 테스트 계정 |
| 광고 | 없음 |
| 콘텐츠 등급 | 설문 작성 (채팅·사용자끼리 소통 있음, 위치 공유 있음) |
| 타겟층 | 18세 이상 (모르는 사람과 위치·메시지를 주고받아서 권장) |
| **데이터 보안** | **위치(정확한 위치)**, 사진, 메시지, 이름·아이디를 모으는지·왜·암호화하는지·지울 수 있는지 |
| 앱 카테고리 | 소셜 |
| 스토어 등록정보 | 짧은 설명, 자세한 설명, 아이콘, 그래픽, 스크린샷 |

## 4. 비공개 테스트 (개인 계정은 필수)

1. **테스트 → 비공개 테스트** → 트랙 만들기
2. 2번의 `.aab` 업로드 → 출시 노트 작성 → 검토 후 출시
3. 테스터 이메일 목록 등록 (구글 그룹 또는 이메일)
4. 테스터에게 **참여 링크**를 보내서 "테스터 되기" + 플레이 스토어에서 설치하게 해요.
5. **12명 이상이 14일 동안 계속** 참여 상태여야 해요. 중간에 빠졌다 다시 들어오면 그 사람은 다시 14일이에요.

## 5. 정식 출시 신청

1. 14일이 지나면 **대시보드 → 프로덕션 액세스 신청**
2. 세 부분 작성: 비공개 테스트 내용(테스터 모집·피드백), 앱 소개(대상·가치·예상 설치 수), 출시 준비(테스트에서 고친 것)
3. 보통 7일 안에 결과가 와요.
4. 승인되면 **프로덕션 → 새 버전 만들기** → `.aab` 업로드 → 출시

## 6. 위치 권한 주의

- 우르르는 앱을 **쓰는 동안만** 위치를 써요 ("앱 사용 중에만 허용"). **백그라운드 위치**를 쓰면 구글 심사가 훨씬 까다로워져요.
- 데이터 보안 양식의 "위치" 항목과 실제 앱 동작이 같아야 해요.
