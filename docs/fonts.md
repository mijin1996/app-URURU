# fonts.md — 우르르 글자(폰트) 정리: 어디서 정하고, 어디에 쓰이나

> 2026-10-21 정리. 줄 번호는 이날 기준이라 파일을 고치면 조금씩 밀릴 수 있어요 (Ctrl+F로 선택자 이름을 찾으면 정확해요).
> 글자 모양을 바꿀 때는 이 문서를 먼저 보고, 바꾼 뒤 이 문서도 같이 고쳐요.

---

## 1. 한눈에 보는 구조

```
index.html 9줄                     글꼴 파일 불러오기 (구글 폰트 Noto Sans KR, 굵기 400·500·700·900)
        │
styles/base.css :root (1–39줄)     ★ 한 곳에서 선언: 글꼴 이름, 크기 이름표(--fs 등)
        │
        ├── styles/base.css        모든 화면 공통 (버튼, 입력 칸, 알림, 창, 하단 탭 …)
        ├── styles/start.css       로고 화면 · 가입 화면 · 이용정지 화면
        ├── styles/home.css        홈(지도) 탭
        ├── styles/chat.css        채팅 탭 + 채팅방 + 전화 화면
        ├── styles/swipe.css       스와이프 탭
        ├── styles/likes.css       친구 탭
        ├── styles/profile.css     전체 화면 프로필 (사진 넘기기)
        ├── styles/story.css       스토리 보기
        └── styles/me.css          나 탭
```

- 각 화면 CSS는 크기를 숫자로 쓰지 않고, `:root`에 선언된 **이름표**(`var(--fs)` 등)를 가져다 써요.
  그래서 **이름표 값 하나를 바꾸면 그 이름표를 쓰는 모든 화면이 같이 바뀌어요.**
- 예외로 숫자를 직접 쓴 곳이 몇 군데 있어요 (아이콘·이니셜·도장 같은 그림 글자, 7장).
- 화면 파일(.jsx)은 글자 모양을 정하지 않고 `className`만 붙여요. 모양은 모두 CSS에서 정해요 (예외 1곳, 7장).
- KR·EN은 같은 CSS를 써요. 언어에 따라 달라지는 건 글자 내용뿐이에요 (`src/core/i18n/ko.js`, `en.js`).

## 2. 글꼴 (font-family)

| 이름표 | 값 | 선언 | 쓰는 곳 |
|---|---|---|---|
| `--body` | Noto Sans KR → 없으면 시스템 글꼴 | `base.css` 38줄 | 앱 전체 기본 글자 (`body`, `base.css` 96줄) |
| `--display` | 위와 같은 글꼴 | `base.css` 25줄 | 크게 보이는 제목·이름: 로고, 스와이프 카드 이름, 나 탭 이름, 전화 화면 이름, 사진 없는 프로필의 큰 이니셜, 그림 지도 지명 |

- 지금은 `--body`와 `--display`가 **같은 글꼴**이에요. 제목만 다른 글꼴로 바꾸고 싶으면 `--display` 한 줄만 바꾸면 돼요.
- 글꼴 파일은 `index.html` 9줄에서 구글 폰트로 불러와요. 굵기 400·500·700·900만 불러와서, CSS에서 다른 굵기(예: 100, 600)를 쓰면 가까운 굵기로 보여요.

## 3. 크기 이름표 (font-size) — `styles/base.css` :root

크기는 **화면 폭에 맞춰 저절로 커지고 작아져요** (`clamp(가장 작게, 폭에 비례, 가장 크게)`).

| 이름표 | 줄 | 폭 390px 폰에서 | 범위 | 쓰는 곳 (개수) |
|---|---|---|---|---|
| `--fs` | 31 | 14px | 12–16px | 기본 글자: 버튼, 입력 칸, 이름, 메시지, 하단 탭 … (36곳) |
| `--fs-small` | 32 | 13px | 12–15px | 회색·설명 글자, 받은 메시지, 시간, 안내 문구 (31곳) |
| `--fs-title` | 33 | 22px | 19–25px | 제목·큰 이름 (9곳) |
| `--fs-profile` | 36 | 10px (고정) | — | 전체 화면 프로필 안의 작은 글자 (8곳) |
| `--logo-size` | `start.css` 28·37 | 44px / 로고 화면 84px | — | "우르르 / Ururu" 로고만 |
| `--icon` | 34 | 20px | 18–23px | 아이콘 크기 (글자 아님) |
| `--btn-h` | 35 | 38px | 34–44px | 버튼·입력 칸 높이 (글자 아님) |

**자주 하는 변경**
- 앱 전체 글자를 키우기/줄이기 → 31·32·33줄의 가운데 숫자(14 / 13 / 22)를 바꿔요.
- 작은 글자를 기본 글자와 같게 → 32줄을 `--fs-small: var(--fs);`
- 프로필 안 글자를 기본 글자와 같게 → 36줄을 `--fs-profile: var(--fs);`

## 4. 굵기 (font-weight)

| 굵기 | 느낌 | 주로 쓰는 곳 |
|---|---|---|
| 400 | 보통 | 따로 정하지 않은 본문 (기본값) |
| 500 | 조금 굵게 | 알림 아래 줄, 스토리 시간, 프로필 동네 |
| 700 | 굵게 | 하단 탭, 칸 이름, 오류 문구, 돌림판에서 고른 줄 |
| 900 | 아주 굵게 | 버튼, 제목, 이름, 태그, 로고 |

굵기는 이름표 없이 각 선택자에 숫자로 적혀 있어요 (아래 5장 표의 "굵기" 칸).
