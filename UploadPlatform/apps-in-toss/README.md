# 앱인토스 등록용 (토스 빌드)

> 앱인토스 콘솔에 넣을 글·그림·파일을 이 폴더 하나에 모았어요. 구글 플레이용은 `store/google-play/`.
> 준수사항 점검은 `docs/policy/compliance.md`, 올리는 순서는 `docs/guides/launch-checklist.md`.
> 글은 **초안**이에요. 미미가 읽고 고친 뒤 콘솔에 붙여 넣으세요.

## 1. 올릴 파일

| 콘솔 칸 | 파일 | 규격 |
|---|---|---|
| 앱 번들 | 프로젝트 맨 위 `ururu.ait` (`npm run build:ait`로 만들어요) | 압축 풀었을 때 100MB 이하 |
| 앱 로고 | `images/logo-600.png` | 600×600 PNG, 배경색 꽉 참, 투명·둥근 모서리 없음 |
| 세로 스크린샷 | `images/screenshot-1.png` ~ `screenshot-4.png` | 636×1048 PNG, 3장 이상 |
| 가로 스크린샷 | `images/screenshot-landscape.png` | 1504×741 PNG, 1장 이상 |

- 스크린샷 순서: 1 채팅 목록 · 2 채팅방 · 3 친구 탭 · 4 나 탭
- 이미지를 다시 만들려면: `npm run build:single` → `npm run build:toss` → `npm run store:images` (덮어써요)

## 2. 기본 정보

| 칸 | 넣을 것 |
|---|---|
| 앱 이름 (국문) | 우르르 |
| 앱 이름 (영문) | Ururu |
| appName | `ururu` (등록 뒤 못 바꿈) |
| 앱 종류 | 비게임 |
| 연령 등급 | 19세 이상 |
| 지원 이메일 | unidevpeer@gmail.com |

| 주요 기능(선택) | 넣지 않아요 (넣으면 `intoss://` 주소가 꼭 맞아야 해요) |

## 3. 부제 (초안, 느낌표·비속어 금지)

```
친구끼리 가볍게 나누는 24시간 대화
```

## 4. 상세 설명 (초안, "들어가기 → 하기 → 결과" 순서로)

```
우르르는 아이디로 친구를 맺은 사람끼리만 대화하는 채팅 앱이에요.

[들어가기]
처음 열면 아이디, 닉네임, 생년월일만 정하면 바로 시작해요. 만 19세 이상만 이용할 수 있어요.

[하기]
- 친구 탭에서 친구의 아이디를 찾아 친구 신청을 보내요. 서로 수락하면 친구가 돼요.
- 친구와 1:1로 글과 음성 메시지를 주고받아요.
- 스토리로 친구들에게 오늘의 근황을 보여줘요.

[결과]
- 메시지와 스토리는 24시간이 지나면 저절로 사라져요. 남기고 싶은 메시지는 두 번 눌러 저장해요.
- 불쾌한 메시지는 길게 눌러 바로 신고하고, 프로필에서 차단할 수 있어요.
- 개인정보 공유, 도박, 욕설은 자동으로 가려지고, 반복해서 어기면 이용이 정지돼요.
```

## 5. 출시 전 채널톡으로 보낼 운영 문서

채팅 서비스는 출시 전에 아래를 채널톡으로 제출해야 해요. 파일을 그대로 보내거나 내용을 붙여 넣으세요.

| 앱인토스가 요구하는 것 | 우르르 파일 |
|---|---|
| 이용자 보호 및 불법 행위 방지 조치 | `docs/policy/chat-rules.md` (채팅 이용 수칙), `docs/policy/report-handling.md` 2장 |
| 기본 서비스 운영 약관 | `docs/policy/terms.md` |
| 운영 정책과 대응 프로세스 (신고 처리, 제재, 수사기관 협조) | `docs/policy/report-handling.md` |
| (함께 내면 좋은 것) 개인정보처리방침 | `docs/policy/privacy.md` |

> 약관·정책 글은 앱의 "나" 탭 → 정책에서도 똑같이 보여요 (앱이 이 .md 파일을 그대로 읽어요).
> 시행일 칸은 "앱인토스에 앱을 제출한 날부터"로 되어 있어요. 제출한 날짜로 바꾸려면 4개 파일 맨 위를 고치고 다시 빌드하세요.
