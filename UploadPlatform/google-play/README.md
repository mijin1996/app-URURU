# 구글 플레이 등록용 (원래 기능 전부)

> 플레이 콘솔에 넣을 글·그림을 이 폴더 하나에 모았어요. 앱인토스용은 `store/apps-in-toss/`.
> 준수사항 점검은 `docs/policy/compliance.md`, 올리는 순서는 `docs/guides/launch-checklist.md`와 `docs/guides/google-play-console-release-guide.md`.
> 글은 **초안**이에요. 미미가 읽고 고친 뒤 콘솔에 붙여 넣으세요.

## 0. 지금 상태 (2026-10-15)

- 그림·글: ✅ 준비됨 (이 폴더)
- **AAB 파일: ❌ 아직 만들 수 없어요.** 안드로이드 프로젝트(Capacitor, `android/` 폴더)가 아직 없어요 → `openspec/changes/add-mobile-apps`
- 진짜 지도·위치: ❌ 아직 그린 지도와 가짜 위치예요 → `openspec/changes/add-google-map`
- 개인정보처리방침·계정 삭제 **웹 주소**: ⏳ 아직 없어요 (`docs/policy/compliance.md` 6장 3번)

## 1. 올릴 그림

| 콘솔 칸 | 파일 | 규격 |
|---|---|---|
| 앱 아이콘 | `images/icon-512.png` | 512×512 PNG (꽉 찬 사각형, 둥근 모양은 구글이 잘라요) |
| 그래픽 이미지 | `images/feature-graphic.jpg` | 1024×500, 알파 없음 |
| 휴대전화 스크린샷 | `images/phone-1.jpg` ~ `phone-6.jpg` | 1080×1920 (9:16), 알파 없음, 2~8장 |

- 스크린샷 순서: 1 홈 지도 · 2 채팅 목록 · 3 채팅방 · 4 스와이프 · 5 친구 탭 · 6 스토리
- 1080×1920 이상 9:16이라 구글의 "큰 화면 추천" 조건(4장 이상)도 맞아요
- 다시 만들기: `npm run build:single` → `npm run build:toss` → `npm run store:images`
- 태블릿·크롬북 스크린샷은 선택이라 만들지 않았어요

## 2. 스토어 등록정보 (초안)

| 칸 | 넣을 것 |
|---|---|
| 앱 이름 (30자) | 우르르 |
| 짧은 설명 (80자) | 가까운 친구와 지도에서 만나고, 24시간 뒤 사라지는 메시지로 가볍게 대화해요 |
| 카테고리 | 소셜 |
| 이메일 | unidevpeer@gmail.com |
| 개인정보처리방침 | ⏳ 웹 주소 (아직 없음) |

자세한 설명 (4000자 이내):

```
우르르는 가까운 친구와 가볍게 모이는 앱이에요.

● 지도에서 친구 보기
위치 공유를 켠 친구가 지도에 보여요. 이름과 거리가 함께 나와서 지금 누가 가까이 있는지 한눈에 알 수 있어요.

● 24시간 뒤 사라지는 메시지
메시지는 하루가 지나면 저절로 사라져서 부담 없이 대화해요. 남기고 싶은 메시지는 두 번 눌러 저장해요.

● 스토리
오늘의 근황을 스토리로 올려요. 테두리가 24시간에 걸쳐 줄어들어서 언제 올렸는지 바로 느껴져요.

● 새 친구
주변 사람을 카드로 넘겨 보며 좋아요를 보내고, 서로 좋아하면 친구가 돼요.

● 안전
불쾌한 메시지는 길게 눌러 바로 신고하고, 프로필에서 차단할 수 있어요. 개인정보 공유·도박·욕설은 자동으로 가려지고, 반복해서 어기면 이용이 정지돼요.

만 19세 이상만 이용할 수 있어요.
```

## 3. 앱 콘텐츠 설문 (초안)

| 항목 | 답 |
|---|---|
| 광고 | 없음 |
| 앱 액세스 | 가입만 하면 모든 기능 사용 가능 → 심사용 안내: "처음 화면에서 아이디·닉네임·생년월일(만 19세 이상)을 넣으면 시작" |
| 타겟층 | 만 18세 이상만 |
| 콘텐츠 등급 | 사용자 간 소통 있음, 사용자 위치 공유 있음, 사용자 제작 콘텐츠(사진·글) 있음 |
| 뉴스 앱 / 정부 앱 / 금융 기능 | 아니요 |
| 계정 삭제 | 앱 안: 나 탭 → 회원탈퇴 / 웹: ⏳ 주소 필요 |

## 4. 데이터 보안 양식 (초안, `docs/policy/privacy.md`와 같게)

| 데이터 | 모음 | 공유 | 왜 | 필수 | 지울 수 있음 |
|---|---|---|---|---|---|
| 위치 (정확한 위치) | 예 (위치 공유를 켤 때만) | 아니요 (친구 화면에 보이는 건 앱 기능) | 앱 기능 | 선택 | 예 |
| 이름 (닉네임), 사용자 ID (아이디) | 예 | 아니요 | 앱 기능, 계정 관리 | 필수 | 예 |
| 생년월일 → "기타 개인 정보" | 예 | 아니요 | 계정 관리 (나이 확인) | 필수 | 예 |
| 사진 (프로필·스토리) | 예 | 아니요 | 앱 기능 | 선택 | 예 |
| 메시지 (글·음성) | 예 | 아니요 | 앱 기능 (24시간 뒤 삭제) | 선택 | 예 |

- 위치를 실제로 받는 코드가 들어간 뒤(`add-google-map`) 이 표를 다시 확인해요
