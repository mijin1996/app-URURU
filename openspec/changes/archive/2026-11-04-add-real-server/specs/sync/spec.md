## Purpose

내가 앱에서 한 일(좋아요, 친구 추가, 메시지, 위치, 스토리)이 서버를 거쳐 다른 사용자 기기에 실제로 전달되는 규칙이에요. 서버 설정이 없을 때의 시연 모드도 정해요.

## ADDED Requirements

### Requirement: 서버 모드와 시연 모드
앱은 서버 설정이 있으면 실제 사용자와 데이터를 주고받고, 없으면 지금처럼 가짜 사람과 자동 답장으로 동작해야 한다(SHALL).

#### Scenario: SYNC-01 시연 모드
- **WHEN** 서버 설정 없이 앱을 연다
- **THEN** 지금과 똑같이 가짜 사람 8명, 자동 답장, 자동 수락으로 동작한다

#### Scenario: SYNC-02 서버 모드
- **WHEN** 서버 설정을 넣고 앱을 연다
- **THEN** 가짜 사람과 자동 답장 없이, 실제 가입한 사용자만 보인다

#### Scenario: SYNC-03 서버 연결 실패
- **WHEN** 서버 모드인데 인터넷이 끊겼다
- **THEN** 배너 "인터넷 연결을 확인해 주세요"가 뜨고, 다시 연결되면 밀린 메시지를 받는다

### Requirement: 좋아요와 친구
좋아요와 친구 맺기는 상대 기기에 실제로 전달되어야 한다(SHALL).

#### Scenario: SYNC-10 좋아요 전달
- **WHEN** A가 B에게 좋아요(또는 아이디로 친구 신청)를 보낸다
- **THEN** B의 친구 탭 "받은 좋아요"에 A가 나타나고 하트 숫자가 1 늘어난다

#### Scenario: SYNC-11 수락
- **WHEN** B가 A의 좋아요에 "친구할까요?"를 누른다
- **THEN** A와 B 모두의 친구 목록·채팅 목록에 서로가 나타나고, A에게 "B님과 친구가 됐어요" 배너가 뜬다

#### Scenario: SYNC-12 서로 좋아요
- **WHEN** 이미 B가 좋아한 상태에서 A도 B에게 좋아요를 보낸다
- **THEN** 바로 서로 친구가 된다

### Requirement: 채팅
메시지와 입력 중 표시는 상대 기기에 실시간으로 전달되어야 한다(SHALL).

#### Scenario: SYNC-20 메시지
- **WHEN** A가 친구 B에게 글·사진·음성 메시지를 보낸다
- **THEN** B 기기에 몇 초 안에 메시지가 나타나고, B가 그 채팅방을 보고 있지 않으면 빨간 숫자·알림음·배너가 뜬다

#### Scenario: SYNC-21 입력 중
- **WHEN** A가 B와의 채팅방에서 글을 쓰는 중이다
- **THEN** B의 대화 목록과 채팅방에 "입력 중"이 보이고, A가 멈추면 사라진다

#### Scenario: SYNC-22 저장
- **WHEN** A가 메시지를 두 번 터치해서 저장한다
- **THEN** 그 메시지는 24시간이 지나도 서버에서 지워지지 않는다

#### Scenario: SYNC-23 24시간 삭제
- **WHEN** 저장하지 않은 메시지가 24시간이 지났다
- **THEN** 앱이 꺼져 있어도 서버에서 지워진다

#### Scenario: SYNC-24 친구만
- **WHEN** 친구가 아닌 사람에게 메시지를 보내려 한다
- **THEN** 서버가 거절한다

### Requirement: 위치 공유
내 위치는 위치 공유가 켜져 있을 때만 친구에게 전달되어야 한다(SHALL).

#### Scenario: SYNC-30 친구에게만
- **WHEN** 위치 공유가 켜진 A가 움직인다
- **THEN** A의 친구들 지도에서만 A의 핀이 움직이고, 친구가 아닌 사람은 A의 정확한 위치를 볼 수 없다

#### Scenario: SYNC-31 고스트 모드
- **WHEN** A가 위치 공유를 끈다
- **THEN** 서버의 A 위치가 더 이상 갱신되지 않고 친구 지도에서 A의 핀이 사라진다

#### Scenario: SYNC-32 모르는 사람 거리
- **WHEN** 친구가 아닌 주변 사람이 지도나 스와이프에 보인다
- **THEN** 정확한 위치 대신 대략의 거리(km)만 보인다

### Requirement: 스토리
스토리는 올리면 친구에게 공개되고, 24시간 뒤 서버에서 지워져야 한다(SHALL).

#### Scenario: SYNC-40 공개
- **WHEN** A가 글·사진 스토리를 올린다
- **THEN** A의 친구 기기에 초록 테두리가 생기고 누르면 스토리가 보인다

#### Scenario: SYNC-41 좋아요
- **WHEN** B가 A의 스토리에 좋아요를 누른다
- **THEN** A에게 배너가 뜨고 A의 "내 스토리 좋아요"에 B가 나타난다

#### Scenario: SYNC-42 24시간
- **WHEN** 스토리를 올린 지 24시간이 지났다
- **THEN** 서버에서 스토리와 사진이 지워진다

### Requirement: 신고 반영
신고한 사람은 서버에서도 서로 보이지 않게 처리되어야 한다(SHALL).

#### Scenario: SYNC-50 서로 안 보임
- **WHEN** A가 B를 신고한다
- **THEN** A와 B는 서로의 친구·채팅·지도·스와이프·아이디 찾기에서 사라지고, 서버에 신고 기록이 남는다
