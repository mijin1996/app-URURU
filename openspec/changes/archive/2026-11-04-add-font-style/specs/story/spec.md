## ADDED Requirements

### Requirement: 폰트 모양
스토리 편집은 일반 폰트와 이탈릭체 중 하나를 고르게 하고, 고른 모양을 입력 칸 · 미리보기 · 올린 스토리에 똑같이 보여줘야 한다(SHALL).

#### Scenario: STO-54 고르기 버튼
- **WHEN** 나 탭 스토리 편집을 본다
- **THEN** 글 입력 칸 아래에 [가 | 가(기울임)] 버튼이 있고 처음에는 "가"(일반)가 골라져 있다

#### Scenario: STO-55 바로 보이기
- **WHEN** 기울인 "가"를 누른다
- **THEN** 글 입력 칸의 글자와 미리보기 글자가 바로 기울어진다

#### Scenario: STO-56 올린 스토리
- **WHEN** 이탈릭체로 스토리를 올린다
- **THEN** 내 작은 그림, 스토리 보기 화면, 친구가 보는 화면 모두 기울인 글자로 보인다

#### Scenario: STO-57 예전 스토리
- **WHEN** 폰트 모양 칸이 없는 예전 스토리를 본다
- **THEN** 일반 폰트로 보인다

## MODIFIED Requirements

### Requirement: 스토리 좋아요
앱은 친구 스토리에 좋아요를 누르고 취소하게 하고, 내 스토리에는 누가 좋아했는지 보여줘야 한다(SHALL).

#### Scenario: STO-15 좋아요
- **WHEN** 친구 스토리 아래 하트를 누른다
- **THEN** 꽉 찬 빨간 하트가 되고, 다시 누르면 취소된다

#### Scenario: STO-15b 사라진 스토리
- **WHEN** 좋아요를 누르는 사이 스토리가 사라졌다
- **THEN** 배너 "스토리가 이미 사라졌어요"가 뜬다

#### Scenario: STO-16 내 스토리 좋아요 없음
- **WHEN** 좋아요가 없는 내 스토리를 본다
- **THEN** 아래에 하트도 글자도 보이지 않는다

#### Scenario: STO-16b 내 스토리 좋아요 있음
- **WHEN** Teo와 서연이 좋아한 내 스토리를 본다
- **THEN** 아래에 빨간 하트 + "Teo, 서연님이 좋아해요"가 보인다

#### Scenario: STO-60 시연 좋아요
- **WHEN** 내가 스토리를 올린다
- **THEN** 3초와 6초 뒤 친구 둘이 좋아요를 눌러 배너가 뜨고 친구 탭 숫자가 늘어난다. 그새 지우거나 새로 올렸으면 무시한다
