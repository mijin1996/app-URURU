## ADDED Requirements

### Requirement: 관심사 키워드
나 탭은 내 관심사 키워드를 최대 5개까지 넣고 지울 수 있게 해야 하고, 넣은 키워드는 내 프로필과 상대의 스와이프 카드에 칩으로 보여야 한다(SHALL).

#### Scenario: PRO-40 상자
- **WHEN** 나 탭을 연다
- **THEN** 사진 상자 아래에 "관심사 n / 5", 넣은 키워드 칩(칸마다 X), 입력 칸 "키워드" + [+]가 보인다. 5개가 차면 입력 칸이 없다

#### Scenario: PRO-41 넣기
- **WHEN** 입력 칸에 "#러닝"을 쓰고 [+]나 Enter를 누른다
- **THEN** "러닝" 칩이 생기고 입력 칸이 비워진다

#### Scenario: PRO-42 안 되는 키워드
- **WHEN** 빈칸, 11자 이상, 이미 있는 키워드를 넣거나 5개가 찬 뒤 넣는다
- **THEN** 각각 배너 "관심사를 입력하세요", "관심사는 10자까지 쓸 수 있어요", "이미 있는 관심사예요", "관심사는 최대 5개까지 넣을 수 있어요"가 뜬다

#### Scenario: PRO-43 지우기와 유지
- **WHEN** 칩의 X를 누르거나 앱을 다시 연다
- **THEN** X를 누른 칩만 지워지고, 남은 키워드는 다시 열어도 그대로다

#### Scenario: PRO-44 내 프로필 미리보기
- **WHEN** 나 탭 맨 위 내 프로필 동그라미를 누른다
- **THEN** 다른 사람에게 보이는 내 전체 화면 프로필이 열리고 관심사가 칩으로 보인다 (거리와 아래 버튼은 없음)
