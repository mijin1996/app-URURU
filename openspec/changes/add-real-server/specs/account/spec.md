## ADDED Requirements

### Requirement: 서버 계정
서버 모드에서 가입 정보는 서버 계정에 저장되어 다른 기기에서도 같은 계정으로 쓸 수 있어야 한다(SHALL).

#### Scenario: ACC-S1 로그인 먼저
- **WHEN** 서버 모드에서 처음 앱을 연다
- **THEN** 로고 다음 빌드에 맞는 방법으로 로그인하고(토스·웹은 화면 없이, 안드로이드는 로그인 화면), 아직 아이디가 없는 사람에게만 가입 화면(아이디·닉네임·생년월일)이 나온다

#### Scenario: ACC-S1b 로그인 실패
- **WHEN** 서버 모드에서 인터넷이 끊겨 로그인하지 못했다
- **THEN** 가입 화면 대신 이유를 배너로 보여주고 잠시 뒤 다시 시도한다

#### Scenario: ACC-S2 다른 기기
- **WHEN** 같은 계정으로 다른 기기에서 로그인한다
- **THEN** 가입 화면 없이 같은 아이디·닉네임·친구·대화가 보인다

#### Scenario: ACC-S3 아이디 중복 (서버)
- **WHEN** 다른 사용자가 이미 쓰는 아이디로 가입하려 한다
- **THEN** 전체 사용자 기준으로 "이미 존재하는 아이디예요"가 뜬다

#### Scenario: ACC-S4 회원탈퇴 (서버)
- **WHEN** 서버 모드에서 회원탈퇴를 한다
- **THEN** 서버의 계정, 프로필, 사진, 메시지, 스토리, 좋아요, 위치가 모두 지워지고 아이디는 다시 쓸 수 있게 된다
