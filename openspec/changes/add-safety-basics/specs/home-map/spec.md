## ADDED Requirements

### Requirement: 위치 정보 동의
앱은 위치를 처음 쓰기 전에 왜 쓰는지 알리고 동의를 받아야 하며, 동의하지 않으면 위치를 모으지 않아야 한다(SHALL).

#### Scenario: SAFE-20 처음 동의
- **WHEN** 처음 홈을 연다
- **THEN** "친구에게 내 위치를 보여주려고 위치를 써요. 위치 공유는 언제든 끌 수 있어요" 동의 창이 기기 위치 권한 창보다 먼저 뜬다

#### Scenario: SAFE-21 동의 안 함
- **WHEN** 동의하지 않는다
- **THEN** 고스트 모드로 시작하고 서버에 내 위치를 보내지 않는다
