## ADDED Requirements

### Requirement: 약관 동의
가입할 때 이용약관과 개인정보처리방침에 동의해야만 가입할 수 있어야 한다(SHALL).

#### Scenario: SAFE-10 동의 안 함
- **WHEN** 약관 동의 칸을 체크하지 않고 "시작하기"를 누른다
- **THEN** "이용약관과 개인정보처리방침에 동의해 주세요"가 뜨고 가입되지 않는다

#### Scenario: SAFE-11 약관 보기
- **WHEN** 동의 칸 옆 "보기"를 누른다
- **THEN** 이용약관(금지 행동 포함)과 개인정보처리방침이 열린다

### Requirement: 앱 밖 회원탈퇴
앱을 지운 사람도 문의 이메일(unidevpeer@gmail.com)로 회원탈퇴와 데이터 삭제를 요청할 수 있어야 한다(SHALL). (구글 플레이 출시 때는 웹 페이지를 따로 만든다)

#### Scenario: SAFE-12 이메일로 탈퇴
- **WHEN** 아이디를 적어 문의 이메일로 탈퇴를 요청한다
- **THEN** 운영자가 7일 안에 서버 함수 deleteAccount와 같은 방법으로 계정과 데이터를 지운다

## MODIFIED Requirements

### Requirement: 닉네임과 생년월일 검사
앱은 닉네임을 앞뒤 공백을 지운 1~12자로, 생년월일을 만 19세 이상인 올바른 날짜로 받아야 한다(SHALL). (2026-10-13 미미: 모든 빌드 만 19세)

#### Scenario: ACC-15 닉네임
- **WHEN** 닉네임을 쓴다
- **THEN** 최대 12자까지 써지고 다른 사람과 같아도 된다

#### Scenario: ACC-19 생년월일 없음
- **WHEN** 생년월일을 고르지 않고 시작한다
- **THEN** "생년월일을 골라주세요"가 보인다

#### Scenario: ACC-19b 만 19세 미만
- **WHEN** 내일이 만 19세 생일인 날짜를 고른다
- **THEN** "만 19세 이상부터 가입할 수 있어요"가 보인다

#### Scenario: ACC-19c 오늘 생일
- **WHEN** 오늘이 만 19세 생일인 날짜를 고른다
- **THEN** 가입할 수 있다
