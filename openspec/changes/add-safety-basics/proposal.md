# Proposal

## Why

구글 플레이와 앱인토스 **둘 다** 사용자끼리 메시지·사진을 주고받는 앱에 같은 안전 장치를 요구해요: 이용약관 동의, 신고·차단, 신고 처리, 위치 같은 민감정보 동의. 구글 플레이는 여기에 **앱 밖에서도 회원탈퇴를 요청할 웹 링크**까지 요구해요. 출시 전에 공통으로 갖춰야 해서 한 변경으로 묶어요.

## What Changes

- **초기 메시지 제한과 대화 규칙** (2026-10-13 추가): 채팅 사진 보내기 끔. 도박·개인정보 공유·욕설은 ****로 가리고 보낸 사람 채팅창에 경고, 경고 2회면 30일 이용 제한. 첫 대화 상대 채팅방에는 규칙 안내. 기능 스위치로 나중에 풀 수 있어요
- **차단**: 채팅방·프로필에서 상대를 차단. 차단하면 서로 메시지·위치·스토리가 안 보여요 (신고와 따로, 신고 없이도 가능)
- **이용약관·개인정보처리방침 동의**: 가입할 때 필수 동의 체크. 금지 행동(괴롭힘, 음란물, 사기 등)을 약관에 적어요
- **위치 정보 동의**: 위치를 처음 쓰기 전에 왜 쓰는지 알려주고 동의 받기
- **신고 처리**: 신고가 들어오면 운영자 메일로 알림, 24시간 안에 확인하는 운영 절차 문서
- **회원탈퇴 웹 링크**: 앱을 지운 사람도 탈퇴를 요청할 수 있는 웹 페이지 (구글 플레이 필수)
- **선행 조건**: `add-real-server` 완료.

**하지 않는 것**: 자동 음란물 필터, 관리자 앱 (처음엔 Firebase 콘솔 + 메일로 처리).

## Capabilities

### New Capabilities
없음

### Modified Capabilities
- `chat`: 차단 요구사항 추가
- `account`: 약관 동의, 회원탈퇴 웹 링크 요구사항 추가
- `home-map`: 위치 정보 동의 요구사항 추가

## Impact

- 화면: 가입 화면 동의 칸, 채팅방·프로필 메뉴에 차단, 나 탭 "차단한 사용자", 위치 동의 창
- 서버: `blocks` 컬렉션 + 보안 규칙, 신고 알림 메일 함수
- 문서: `docs/policy/terms.md`, `docs/policy/privacy.md`, `docs/policy/report-handling.md`, 회원탈퇴 웹 페이지(Firebase Hosting)
