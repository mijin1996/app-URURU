# Proposal

## Why

React 전환 뒤 미미가 화면을 직접 보고 정한 다듬기예요. 지도는 넓게, 위치는 각자 "나" 탭에서 켠 친구끼리만 보이게, 쓸데없이 긴 안내 문구는 지우고, 스토리 만들기 버튼을 쓰기 쉽게 바꿔요.

## What Changes

사용자가 보는 화면과 동작이 바뀌어요.

| 화면 | 바뀌는 것 |
|---|---|
| 홈 | 아래 사람 카드 줄과 지도 위 "위치 공유 중" 알약 버튼을 없애고 지도를 꽉 차게. **모르는 사람은 지도에 안 보이고**, 친구도 **그 친구가 자기 "나" 탭에서 위치 공유를 켰을 때만** 보여요 |
| 나 · 설정 | 위치 공유는 "친구와 위치 공유" 토글 **한 곳에서만** 켜고 꺼요 (켜면 친구 지도에 내가 보임). 설정 세 줄의 설명 글을 지워요 |
| 채팅 탭 | 안내 둘째 줄 "남기고 싶은 메시지는 두 번 터치해서 저장하세요." → "두 번 터치해서 메시지 저장" |
| 채팅방 | 상대 프로필은 프로필 동그라미를 눌러야만 열림. 상태 글자의 "· 프로필 보기", 맨 위 안내 "메시지는 24시간 뒤 사라져요 · 두 번 터치하면 저장", 말풍선 아래 시간 글자(내 것·받은 것 모두) 삭제. 저장한 메시지의 "저장됨"만 남김 |
| 스와이프 | 1시간에 **10명** (5명에서). 제목 아래 "이번 1시간에 n / 5명 더 볼 수 있어요"와 카드의 "눌러서 사진 n장 보기"를 지워요 |
| 친구 탭 | 검색칸 "아이디로 친구 찾기" → "친구 찾기". 받은 좋아요 줄의 "나에게 좋아요를 보냈어요 · 5분" 지우기. "내 스토리 좋아요" 소제목 → "좋아요를 받았어요". 스토리가 없을 때 안내 글 지우기 |
| 나 · 사진 | 안내 글을 지우고, 그 자리만큼 사진 칸을 크게 (한 줄 3칸) |
| 나 · 스토리 | [사진으로 스토리 올리기] → 편집 줄 왼쪽 [사진 추가] (미리보기 바탕에 넣기만), [스토리 올리기]는 오른쪽. 크기 막대를 색 칸 위로 |
| 모든 탭 | 홈 · 채팅 · 스와이프 · 친구 왼쪽 위 제목("모여", "채팅", "스와이프", "친구") 삭제 |
| 앱인토스 빌드 | 스와이프·홈(지도) 탭과 "친구와 위치 공유" 토글을 빼서 탭 3개(채팅 · 친구 · 나), 시작 탭은 채팅 (`canShareLocation` 스위치 추가) |
| 크기 규칙 | 폰트·아이콘·버튼 크기가 앱 폭에 맞춰 저절로 커지고 작아짐 (390px 폰에서 지금 크기, 320px 폰에서 글자 12px). 이름과 나이는 같은 글꼴·크기·굵기 |

**하지 않는 것 (Non-goals)**
- 친구마다 따로 위치를 켜고 끄기 (채팅방 토글) — 미미 결정으로 하지 않음
- 채팅방 입력창 "+" 메뉴 — 하지 않음
- 1시간마다 정해진 시각에 한꺼번에 풀리는 방식 — 지금처럼 "가장 먼저 본 사람이 1시간을 채우면 한 자리씩 열림"
- 진짜 서버의 위치 공유 (→ `add-real-server`)

## Capabilities

### New Capabilities
없음

### Modified Capabilities
- `app-shell`: 크기 규칙(폭에 맞춰), 탭 제목 없음, 이름·나이 통일
- `home-map`: 지도 구성, 핀(친구만·위치 공유 켠 친구만), 홈에서 누르기(카드 없음), 위치 공유 알약 삭제, 위치 움직임
- `account`: 나 탭 설정 (설명 글 없음, 위치 공유는 여기서만)
- `chat`: 채팅 탭 안내 문구, 채팅방 위쪽(프로필은 동그라미로만), 메시지 보이기(안내·시간 글자 삭제)
- `swipe`: 1시간 10명, 남은 수 글자·사진 장수 글자 삭제
- `friends`: 검색칸 문구, 받은 좋아요 줄, "좋아요를 받았어요"
- `profile`: 프로필 사진 상자 (안내 글 없음, 칸 크게)
- `story`: 스토리 만들기 버튼, 크기 막대와 색 칸 순서

## Impact

- `src/core/config.js` (`SWIPE_LIMIT` 10), `src/data/sampleData.js` (친구마다 `isSharing`), `src/data/UserStore.js` (`friendsOnMap()`)
- `src/platform/features.js`: `canSeeStrangers`를 지움 (지도에 모르는 사람이 어느 빌드에서도 안 나와서 필요 없음), `canShareLocation` 추가 (토스 false — 홈 탭·위치 공유 토글 없음)
- 화면: `screens/home/*` (`PersonCard.jsx`, `SharePill.jsx` 지움), `ChatListScreen`, `screens/swipe/*`, `screens/friends/*`, `screens/me/*`
- CSS: `home.css`(카드 줄·알약 삭제), `me.css`(사진 칸 3열, 편집 줄 버튼)
- 시험: `tests/*` (10명, 지도 친구), `tools/compare` (원본 비교 → 승인한 화면과 비교)
- 문서: `docs/file-tree.md`, `docs/code-structure-and-patterns.md`, `openspec/changes/add-build-targets`
