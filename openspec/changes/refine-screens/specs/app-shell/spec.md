## MODIFIED Requirements

### Requirement: 앱 틀과 크기 규칙
앱은 폭 최대 440px 틀 안에 그려지고, 폰트·아이콘·버튼 크기는 앱 폭에 맞춰 저절로 커지고 작아지되 모든 화면에 같은 규칙으로 적용해야 한다(SHALL).

#### Scenario: SHELL-01 PC에서 열기
- **WHEN** 화면 폭이 600px 이상이다
- **THEN** 앱 틀이 가운데에 높이 최대 900px, 둥근 모서리 32px, 테두리와 그림자가 있는 폰 모양으로 보인다

#### Scenario: SHELL-02 밝은·어두운 모드
- **WHEN** 기기 설정이 어두운 모드다
- **THEN** 앱도 어두운 색으로 보인다

#### Scenario: SHELL-03 글꼴과 크기
- **WHEN** 폭 390px 폰에서 화면을 그린다
- **THEN** 글꼴은 Noto Sans KR 하나, 일반 폰트 14px, 보조 폰트 13px, 제목 22px, 아이콘 20px이다

#### Scenario: SHELL-03b 폭에 맞춰 크기
- **WHEN** 폭 320px 폰이나 폭 440px 이상(PC)에서 화면을 그린다
- **THEN** 크기가 폭에 비례해 바뀌되 일반 폰트는 12px~16px, 보조 폰트 12px~15px, 제목 19px~25px, 아이콘 18px~23px 안에 있고, 화면 밖으로 가로로 넘치는 것이 없다

#### Scenario: SHELL-04 버튼 모양
- **WHEN** 글자나 그림이 들어간 버튼을 그린다
- **THEN** 높이는 폭 390px에서 38px(34px~43px), 양옆 16px의 알약 모양이고 내용 길이만큼만 넓으며, 버튼 줄은 오른쪽 정렬이다

#### Scenario: SHELL-05 움직임 줄이기
- **WHEN** 기기에서 "움직임 줄이기"가 켜져 있다
- **THEN** 모든 애니메이션과 전환 효과가 꺼진다

#### Scenario: SHELL-06 이름과 나이
- **WHEN** 이름과 나이를 함께 보여준다 (스와이프 카드, 프로필, 친구 탭)
- **THEN** 나이는 이름과 같은 글꼴·크기·굵기다

### Requirement: 하단 탭
앱은 아래에 탭을 같은 너비로 보여주고(기능이 다 켜진 빌드는 5개), 탭 화면 맨 위에는 제목을 두지 않아야 한다(SHALL).

#### Scenario: SHELL-20 탭 순서
- **WHEN** 하단 탭을 그린다
- **THEN** 홈(지도) · 채팅(말풍선) · 스와이프(카드) · 친구(꽉 찬 하트) · 나(사람) 순서로 같은 너비다

#### Scenario: SHELL-20b 기능이 꺼진 빌드
- **WHEN** 앱인토스 빌드(`canSwipe`·`canShareLocation` 끔)에서 하단 탭을 그린다
- **THEN** 채팅 · 친구 · 나 3개만 같은 너비로 나오고, 시작 탭은 채팅이다 (build-targets TGT-01)

#### Scenario: SHELL-21 지금 탭 표시
- **WHEN** 어떤 탭이 선택되어 있다
- **THEN** 그 탭은 진하게 보이고 아래에 점이 있다

#### Scenario: SHELL-22 빨간 숫자
- **WHEN** 안 읽은 메시지나 수락 기다리는 좋아요·안 본 내 스토리 좋아요가 있다
- **THEN** 채팅 탭에 안 읽은 메시지 전체 수, 친구 탭에 좋아요 수의 합이 빨간 숫자로 보이고, 0이면 안 보인다

#### Scenario: SHELL-23 숫자 위치
- **WHEN** 빨간 숫자가 보인다
- **THEN** 아이콘 오른쪽 위에 겹쳐 보이고 탭 글자를 밀어내지 않는다

#### Scenario: SHELL-24 탭 누르기
- **WHEN** 탭을 누른다
- **THEN** 그 화면으로 바뀐다. 처음 시작할 때는 홈이다

#### Scenario: SHELL-25 탭 제목 없음
- **WHEN** 홈 · 채팅 · 스와이프 · 친구 탭을 그린다
- **THEN** 왼쪽 위에 "모여" · "채팅" · "스와이프" · "친구" 같은 제목 글자가 없고 바로 내용이 시작된다

#### Scenario: SHELL-26 고정 화면
- **WHEN** 홈 또는 스와이프 탭이다
- **THEN** 화면이 스크롤되지 않는다. 나머지 탭은 위아래로 스크롤된다
