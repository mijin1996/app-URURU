## MODIFIED Requirements

### Requirement: 채팅 탭 구성
채팅 탭은 스토리 줄, 안내 상자, "대화" 소제목, 대화 목록을 순서대로 보여줘야 한다(SHALL). 맨 위 제목은 없다.

#### Scenario: CHAT-01 순서
- **WHEN** 채팅 탭을 연다
- **THEN** 위에서부터 스토리 줄, 안내 상자, "대화", 대화 목록이다 (제목 "채팅" 없음)

#### Scenario: CHAT-06 안내 상자
- **WHEN** 채팅 탭을 그린다
- **THEN** 종 아이콘 + "메시지는 24시간 뒤 사라져요" / "두 번 터치해서 메시지 저장"이 보인다

### Requirement: 채팅방 위쪽
채팅방은 위쪽에 뒤로·상대 정보·전화·신고 버튼을 보여주고, 상대 프로필은 프로필 동그라미를 눌렀을 때만 열어야 한다(SHALL).

#### Scenario: CHAT-20 버튼 순서
- **WHEN** 채팅방을 연다
- **THEN** [뒤로] [38px 프로필 동그라미] 이름 + 상태 [전화] [빨간 깃발 신고]가 보인다

#### Scenario: CHAT-21 상태 글자
- **WHEN** 상대가 입력 중이다
- **THEN** 상태 글자가 "입력 중 ●●●"이고, 아니면 "1.2km"다 ("프로필 보기" 글자는 없음)

#### Scenario: CHAT-22 프로필
- **WHEN** 상대 프로필 동그라미를 누른다
- **THEN** 버튼 없는 프로필이 열린다. 이름이나 상태 글자를 누르면 아무 일도 없다

#### Scenario: CHAT-23 읽음
- **WHEN** 채팅방을 연다
- **THEN** 그 대화의 빨간 숫자가 0이 된다

#### Scenario: CHAT-24 뒤로
- **WHEN** 뒤로를 누른다
- **THEN** 채팅방이 닫히고 뒤 화면이 갱신된다

#### Scenario: CHAT-25 배너로 열기
- **WHEN** 프로필·스토리·팝업·다른 채팅방이 열린 상태에서 알림 배너를 눌러 채팅방을 연다
- **THEN** 열려 있던 창이 모두 닫히고 이 채팅방만 남는다

### Requirement: 메시지 보이기
채팅방은 내 메시지와 받은 메시지를 구분해 보여주고, 시간 글자 없이 저장한 메시지에만 "저장됨"을 보여줘야 한다(SHALL).

#### Scenario: CHAT-30 맨 위 안내 없음
- **WHEN** 채팅방을 연다
- **THEN** 맨 위에 안내 글이 없고 바로 메시지가 보인다

#### Scenario: CHAT-31 양쪽 구분
- **WHEN** 메시지를 그린다
- **THEN** 내 메시지는 오른쪽 14px, 받은 메시지는 왼쪽 13px 글자다

#### Scenario: CHAT-32 시간 글자 없음
- **WHEN** 메시지를 그린다
- **THEN** 내 메시지와 받은 메시지 모두 말풍선 아래에 보낸 시각·남은 시간 글자가 없다. 저장한 메시지만 아래에 "저장됨"이 보인다

#### Scenario: CHAT-33 사진 메시지
- **WHEN** 사진 메시지를 그린다
- **THEN** 사진 말풍선이 보인다

#### Scenario: CHAT-34 음성 메시지
- **WHEN** 음성 메시지를 그리고 한 번 터치한다
- **THEN** 재생 아이콘 + 파형 막대 16개 + "0:05"가 보이고, 터치하면 2초 동안 재생 애니메이션이 나온다

#### Scenario: CHAT-35 입력 중 말풍선
- **WHEN** 상대가 입력 중이다
- **THEN** 맨 아래 왼쪽에 점 3개 말풍선이 보인다

#### Scenario: CHAT-36 맨 아래로
- **WHEN** 새 메시지가 오거나 채팅방을 다시 그린다
- **THEN** 항상 맨 아래 최신 메시지가 보인다
