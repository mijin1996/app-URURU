## MODIFIED Requirements

### Requirement: 스와이프 화면
스와이프 탭은 카드 더미와 X·하트 버튼을 보여주고, 1시간에 10명까지만 보여줘야 한다(SHALL). 남은 수 글자는 보여주지 않는다.

#### Scenario: SWP-01 고정 화면
- **WHEN** 스와이프 탭을 연다
- **THEN** 맨 위 제목 글자 없이 카드부터 보이고 화면은 스크롤되지 않는다

#### Scenario: SWP-02 1시간에 10명
- **WHEN** 카드를 넘긴다 (좋아요든 X든)
- **THEN** 최근 1시간 안에 넘긴 사람이 10명이 되면 더 볼 수 없고, 가장 먼저 넘긴 사람이 1시간을 채우면 한 자리가 다시 열린다. 이것이 계속 되풀이된다. 제목 아래 남은 수 글자는 없다

#### Scenario: SWP-03 카드 더미
- **WHEN** 볼 사람이 여러 명이다
- **THEN** 맨 위 카드와 뒤에 살짝 보이는 카드 1장이 있다. 남은 수가 1이면 1장만 있다

#### Scenario: SWP-04 카드 내용
- **WHEN** 카드를 그린다
- **THEN** 대표 사진, 아래 어둡게, 처음엔 안 보이는 "좋아요"·"넘기기" 도장, 이름 + 나이(이름과 같은 글꼴·크기·굵기) + 초록 점, "➤ 1.2km · 동네", 관심사 칩이 있고 "눌러서 사진 n장 보기" 글자는 없다

#### Scenario: SWP-05 버튼
- **WHEN** 카드가 있다
- **THEN** 카드 아래 동그란 [X] [하트] 버튼이 있다

### Requirement: 다 봤을 때
스와이프는 볼 사람이 없으면 이유와 다시 볼 수 있는 때를 알려주고, 그때가 되면 저절로 다시 그려야 한다(SHALL).

#### Scenario: SWP-40 버튼 숨김
- **WHEN** 볼 카드가 없다
- **THEN** 카드 자리에 안내 2줄이 보이고 X와 하트 버튼이 사라진다

#### Scenario: SWP-41 10명 다 봄
- **WHEN** 최근 1시간 안에 10명을 다 봤다
- **THEN** "1시간에 10명까지 볼 수 있어요."와 "n분 뒤에 다시 볼 수 있어요."가 보인다. n분은 가장 먼저 본 한 명이 1시간을 채우는 때까지, 최소 1분, 올림이다

#### Scenario: SWP-42 사람 없음
- **WHEN** 남은 수는 있지만 볼 사람이 없고 X 한 사람이 있다
- **THEN** "14세"와 X 한 사람 중 가장 먼저 돌아오는 때까지의 "n분 뒤에 다시 볼 수 있어요."가 보인다

#### Scenario: SWP-42b 기다릴 사람도 없음
- **WHEN** 볼 사람도 X 한 사람도 없다
- **THEN** "14세"와 "새로운 사람이 생기면 보여드릴게요."가 보인다

#### Scenario: SWP-44 저절로 다시 그리기
- **WHEN** 스와이프 탭을 보고 있는 중에 다시 볼 수 있는 시각이 된다
- **THEN** 화면이 저절로 다시 그려진다

#### Scenario: SWP-45 다시 열면
- **WHEN** 앱을 다시 연다
- **THEN** (시제품 한계) 10명부터 다시 시작한다
