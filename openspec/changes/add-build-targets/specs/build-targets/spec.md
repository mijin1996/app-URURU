## Purpose

같은 코드로 앱인토스용, 구글 플레이용, 시연용 웹을 빌드할 때 빌드 대상마다 로그인 방법, 켜는 기능, 나이 제한을 다르게 정하는 규칙이에요.

## ADDED Requirements

### Requirement: 앱인토스 빌드는 친구 채팅만
앱인토스 빌드는 모르는 사람과 연결하는 기능과 위치 기능을 모두 꺼서, 아이디로 맺은 친구끼리만 쓰게 해야 한다(SHALL). 꺼진 기능의 코드는 지우지 않고 기능 스위치(`canSwipe`, `canShareLocation`)로만 끈다.

#### Scenario: TGT-01 탭 3개
- **WHEN** 앱인토스 빌드를 연다
- **THEN** 하단 탭이 채팅 · 친구 · 나 3칸이고 스와이프·홈(지도) 탭이 없으며, 처음 보이는 탭은 채팅이다

#### Scenario: TGT-02 위치 없음
- **WHEN** 앱인토스 빌드의 나 탭 설정을 본다
- **THEN** "친구와 위치 공유" 토글이 없고, 앱이 위치를 묻거나 서버에 보내지 않는다 (위치기반서비스 신고·동의 창을 마친 뒤 `canShareLocation`을 켬)

#### Scenario: TGT-03 친구 추가
- **WHEN** 앱인토스 빌드에서 친구를 추가한다
- **THEN** 친구 탭의 아이디 찾기로만 친구 신청을 보낼 수 있다

#### Scenario: TGT-04 토스 자동 로그인 (처음)
- **WHEN** 토스 앱 안에서 우르르를 처음 연다
- **THEN** 로그인 화면 없이 토스 익명 사용자 키로 사용자를 구분하고, 아직 가입하지 않은 사람에게만 가입 화면(아이디·닉네임·생년월일)이 나온다

#### Scenario: TGT-04b 토스 자동 로그인 (다음부터)
- **WHEN** 한 번 가입한 사람이 토스 앱 안에서 우르르를 다시 연다
- **THEN** 로그인 화면 없이 바로 첫 탭(채팅)이 나와서 친구와 소통할 수 있다

#### Scenario: TGT-06 오래된 토스 앱
- **WHEN** 익명 사용자 키를 지원하지 않는 토스 앱(5.232.0 미만)에서 연다
- **THEN** 배너 "토스 앱을 최신 버전으로 업데이트해 주세요"가 뜨고 잠시 뒤 다시 시도한다

#### Scenario: TGT-05 나이
- **WHEN** 앱인토스 빌드에서 만 19세 미만 생년월일로 가입하려 한다
- **THEN** "만 19세 이상부터 가입할 수 있어요"가 뜬다

### Requirement: 앱인토스 출시 체크리스트 맞추기
앱인토스 빌드는 비게임 출시 체크리스트의 화면 규칙을 지켜야 한다(SHALL). 스위치는 `src/platform/features.js` (`askPingOnStart`, `lightThemeOnly`, `ownBackButtons`). (2026-10-15, `docs/policy/compliance.md` 2장)

#### Scenario: TGT-07 뒤로가기
- **WHEN** 앱인토스 빌드에서 채팅방이나 친구 목록을 연다
- **THEN** 왼쪽 위 자체 뒤로 버튼이 없고, 토스 뒤로가기(내비게이션 바·안드로이드 뒤로 버튼)를 누르면 맨 위 창이 닫힌다. 닫을 창이 없으면 미니앱이 종료된다. 이용정지 안내·가입 화면은 뒤로가기로 닫히지 않는다

#### Scenario: TGT-08 라이트 모드
- **WHEN** 폰이 다크 모드인 상태로 앱인토스 빌드를 연다
- **THEN** 밝은 화면으로 보인다

#### Scenario: TGT-09 진입 직후 창 없음
- **WHEN** 앱인토스 빌드에서 가입을 마친다
- **THEN** "소리 울리기를 받을까요?" 창이 저절로 뜨지 않는다 (나 탭 설정에서는 켤 수 있다)

#### Scenario: TGT-09b 거리 없음
- **WHEN** 앱인토스 빌드에서 채팅방·친구 목록·프로필을 본다
- **THEN** 거리(km)가 보이지 않는다

#### Scenario: TGT-09c 확대 없음
- **WHEN** 두 손가락으로 화면을 벌린다
- **THEN** 화면이 확대되지 않는다 (모든 빌드)

### Requirement: 구글 플레이 빌드는 전체 기능
구글 플레이 빌드는 모든 기능을 켜고 구글 로그인을 써야 한다(SHALL).

#### Scenario: TGT-10 탭 5개
- **WHEN** 구글 플레이 빌드를 연다
- **THEN** 하단 탭이 홈 · 채팅 · 스와이프 · 친구 · 나 5칸이다

#### Scenario: TGT-11 계정 연동 가입·로그인
- **WHEN** 구글 플레이 빌드를 처음 연다
- **THEN** [구글로 계속하기]와 [이메일로 계속하기] 버튼이 보이고, 처음이면 가입 화면, 이미 가입했으면 바로 홈으로 간다

#### Scenario: TGT-11b 다음부터 자동
- **WHEN** 로그인한 적 있는 사람이 앱을 다시 연다
- **THEN** 로그인 화면 없이 바로 홈이 나온다

#### Scenario: TGT-12 나이
- **WHEN** 구글 플레이 빌드에서 만 18세 미만 생년월일로 가입하려 한다
- **THEN** "만 18세 이상부터 가입할 수 있어요"가 뜬다 (모르는 사람과 위치·메시지를 주고받는 기능이 있어서)

### Requirement: 시연용 웹 빌드
시연용 한 장 HTML은 로그인 없이 가짜 서버로 전체 기능을 보여줘야 한다(SHALL).

#### Scenario: TGT-20 시연
- **WHEN** 더블클릭 HTML을 연다
- **THEN** 지금처럼 가입 화면부터 시작하고 가짜 사람과 자동 답장으로 모든 기능을 눌러볼 수 있다
