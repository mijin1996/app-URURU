## MODIFIED Requirements

### Requirement: 가입 화면 구성
가입 화면은 정해진 순서와 문구로 아이디·닉네임·생년월일 칸을 보여줘야 한다(SHALL).

#### Scenario: ACC-10 순서
- **WHEN** 가입 화면을 그린다
- **THEN** 위에서부터 "우르르" 로고(44px), "처음 오셨네요!", 아이디 칸, 아이디 검사 문구, 닉네임 칸, 생년월일 칸, 오류 문구, "시작하기" 버튼이고, 모두 화면 가로 가운데에 맞춰 놓인다. 칸 이름·검사 문구·오류 문구는 입력 칸 왼쪽 테두리에 맞춰 왼쪽 정렬이다

#### Scenario: ACC-11 안내 문단 없음
- **WHEN** 가입 화면을 그린다
- **THEN** "처음 오셨네요!" 아래에 안내 문단 없이 바로 아이디 칸이 나온다

#### Scenario: ACC-12 아이디 칸
- **WHEN** 아이디 칸을 그린다
- **THEN** 이름은 "아이디 · 영어와 숫자만", 예시 글은 "예: ururu123", 최대 15자이고 자동 대문자·맞춤법 검사가 꺼져 있다
