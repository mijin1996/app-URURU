## ADDED Requirements

### Requirement: 키가 있으면 실제 지도
앱은 구글 지도 API 키가 설정되어 있으면 홈에 구글 지도를 보여주고, 키가 없으면 지금 그림 지도를 그대로 보여줘야 한다(SHALL).

#### Scenario: MAP-40 키 없음
- **WHEN** API 키를 넣지 않고 앱을 연다
- **THEN** 홈에 지금과 똑같은 그림 지도가 보이고 기존 홈 시나리오가 모두 그대로 동작한다

#### Scenario: MAP-41 키 있음
- **WHEN** 올바른 API 키를 넣고 앱을 연다
- **THEN** 홈에 구글 지도가 보이고, 그 위에 핀·"이름 · 거리"·위치 공유 버튼·카드 줄이 그림 지도 때와 같은 규칙으로 보인다

#### Scenario: MAP-42 지도 글자
- **WHEN** 기기 언어가 영어인 사람이 연다
- **THEN** 지도 지명이 그 사람 기기 언어로 보인다

### Requirement: 지도를 못 불러오면 그림 지도로
앱은 구글 지도를 불러오지 못하면 멈추지 않고 그림 지도로 넘어가며 이유를 알려야 한다(SHALL).

#### Scenario: MAP-43 키가 틀림
- **WHEN** 잘못된 키를 넣고 앱을 연다
- **THEN** 그림 지도가 보이고 배너 "지도를 불러오지 못해 기본 지도를 보여줘요"가 뜬다

#### Scenario: MAP-43b 인터넷 끊김
- **WHEN** 인터넷이 끊긴 채 홈을 연다
- **THEN** 그림 지도가 보이고 같은 배너가 뜨며 나머지 기능은 그대로 쓸 수 있다

### Requirement: 내 실제 위치
키가 있을 때 앱은 위치 권한을 물은 뒤 기기의 실제 위치를 내 핀 자리로 써야 한다(SHALL).

#### Scenario: MAP-44 처음 묻기
- **WHEN** 키가 있는 상태로 홈을 처음 연다
- **THEN** 기기의 위치 권한 창이 뜬다

#### Scenario: MAP-45 허용
- **WHEN** 위치 권한을 허용한다
- **THEN** 지도가 내 실제 위치를 가운데로 보여주고 내 핀이 그 자리에 있다

#### Scenario: MAP-46 거절
- **WHEN** 위치 권한을 거절한다
- **THEN** 지도는 기본 위치를 보여주고 배너 "위치 권한을 켜면 내 위치가 지도에 보여요"가 뜬다

#### Scenario: MAP-47 고스트 모드
- **WHEN** 위치 공유를 끈다
- **THEN** 내 핀이 회색이 되고 친구에게 내 위치를 보내지 않는다 (기존 MAP-23과 같은 규칙)

### Requirement: 실제 지도 위 시연 친구
키가 있을 때 시연용 친구들은 내 실제 위치 근처에 놓이고, 거리는 실제 좌표로 계산해야 한다(SHALL).

#### Scenario: MAP-48 근처에 놓기
- **WHEN** 키가 있고 내 위치를 알았다
- **THEN** 시연 친구들이 내 위치 반경 몇 km 안에 놓이고 "이름 · 1.2km"의 거리가 실제 좌표 사이 거리로 계산된다
