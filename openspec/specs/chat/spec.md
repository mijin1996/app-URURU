# chat Specification

## Purpose

친구와 1:1로 대화하는 채팅이에요. 채팅 탭(스토리 줄과 대화 목록), 24시간 뒤 사라지는 메시지, 두 번 터치 저장, 사진·음성 메시지, 전화 화면, 신고를 다뤄요.

## Requirements

### Requirement: 채팅 탭 구성
채팅 탭은 제목, 스토리 줄, 안내 상자, "대화" 소제목, 대화 목록을 순서대로 보여줘야 한다(SHALL).

#### Scenario: CHAT-01 순서
- **WHEN** 채팅 탭을 연다
- **THEN** 위에서부터 제목 "채팅", 스토리 줄, 안내 상자, "대화", 대화 목록이다

#### Scenario: CHAT-06 안내 상자
- **WHEN** 채팅 탭을 그린다
- **THEN** 종 아이콘 + "메시지는 24시간 뒤 사라져요" / "남기고 싶은 메시지는 두 번 터치해서 저장하세요."가 보인다

### Requirement: 스토리 줄
채팅 탭 스토리 줄은 맨 앞에 내 스토리, 뒤로 스토리를 올린 친구만 둥근 네모 사진으로 보여주고, 아래 이름 글자는 보여주지 않아야 한다(SHALL).

#### Scenario: CHAT-02 칸 모양
- **WHEN** 스토리 줄을 그린다
- **THEN** 모든 칸이 둥근 네모 사진이고 아래 이름 글자가 없다

#### Scenario: CHAT-03 내 스토리 없음
- **WHEN** 내 스토리가 없다
- **THEN** 내 칸에 "+"가 보이고, 테두리 자리만큼 비워 둬서 친구 칸들과 크기·줄이 맞다

#### Scenario: CHAT-04 내 칸 누르기
- **WHEN** 내 칸을 누른다
- **THEN** 내 스토리가 있으면 내 스토리가 열리고, 없으면 나 탭으로 간다

#### Scenario: CHAT-05 친구 칸 누르기
- **WHEN** 친구 칸을 누른다
- **THEN** 그 친구 스토리가 열린다

### Requirement: 대화 목록
채팅 탭은 신고하지 않은 모든 친구를 최근 대화 순으로, 프로필·이름·미리보기·안 읽은 수와 함께 보여줘야 한다(SHALL).

#### Scenario: CHAT-07 줄 모양
- **WHEN** 대화 목록을 그린다
- **THEN** 줄마다 56px 동그란 프로필, 이름, 미리보기, 안 읽은 메시지가 있으면 빨간 숫자가 있다

#### Scenario: CHAT-08 순서
- **WHEN** 두 친구 중 한 명과 더 최근에 대화했다
- **THEN** 그 친구가 위에 있다

#### Scenario: CHAT-09 입력 중 미리보기
- **WHEN** 상대가 입력 중이다
- **THEN** 미리보기 자리에 움직이는 "입력 중 ●●●"이 보인다

#### Scenario: CHAT-09b 마지막 메시지 미리보기
- **WHEN** 마지막 메시지가 내가 5분 전에 보낸 사진이다
- **THEN** 미리보기가 "나: 사진 · 5분"이다 (음성은 "음성 메시지")

#### Scenario: CHAT-09c 메시지 없음
- **WHEN** 아직 대화가 없다
- **THEN** 미리보기가 "대화를 시작해 보세요"다

#### Scenario: CHAT-10 안 읽음 강조
- **WHEN** 안 읽은 메시지가 있다
- **THEN** 미리보기가 진하게 보이고 오른쪽에 빨간 숫자가 있다

#### Scenario: CHAT-11 열기
- **WHEN** 줄을 누른다
- **THEN** 그 친구 채팅방이 열린다

### Requirement: 채팅방 위쪽
채팅방은 위쪽에 뒤로·상대 정보·전화·신고 버튼을 보여줘야 한다(SHALL).

#### Scenario: CHAT-20 버튼 순서
- **WHEN** 채팅방을 연다
- **THEN** [뒤로] [38px 프로필 + 이름 + 상태] [전화] [빨간 깃발 신고]가 보인다

#### Scenario: CHAT-21 상태 글자
- **WHEN** 상대가 입력 중이다
- **THEN** 상태 글자가 "입력 중 ●●●"이고, 아니면 "1.2km · 프로필 보기"다

#### Scenario: CHAT-22 프로필
- **WHEN** 상대 정보 부분을 누른다
- **THEN** 버튼 없는 프로필이 열린다

#### Scenario: CHAT-23 읽음
- **WHEN** 채팅방을 연다
- **THEN** 그 대화의 빨간 숫자가 0이 된다

#### Scenario: CHAT-24 뒤로
- **WHEN** 뒤로를 누른다
- **THEN** 채팅방이 닫히고 뒤 화면이 갱신된다

#### Scenario: CHAT-25 배너로 열기
- **WHEN** 프로필·스토리·팝업·다른 채팅방이 열린 상태에서 알림 배너를 눌러 채팅방을 연다
- **THEN** 열려 있던 창이 모두 닫히고 이 채팅방만 남는다

### Requirement: 메시지 보이기
채팅방은 내 메시지와 받은 메시지를 구분하고, 각 메시지의 남은 시간이나 저장 상태를 보여줘야 한다(SHALL).

#### Scenario: CHAT-30 맨 위 안내
- **WHEN** 채팅방을 연다
- **THEN** 맨 위에 작게 "메시지는 24시간 뒤 사라져요 · 두 번 터치하면 저장"이 보인다

#### Scenario: CHAT-31 양쪽 구분
- **WHEN** 메시지를 그린다
- **THEN** 내 메시지는 오른쪽 14px, 받은 메시지는 왼쪽 13px 글자다

#### Scenario: CHAT-32 남은 시간
- **WHEN** 저장하지 않은 메시지를 그린다
- **THEN** 말풍선 아래에 "5분 · 23시간 남음"처럼 보이고, 1시간 미만 남으면 "n분 남음"이다. 저장한 메시지는 "저장됨"이다

#### Scenario: CHAT-33 사진 메시지
- **WHEN** 사진 메시지를 그린다
- **THEN** 사진 말풍선이 보인다

#### Scenario: CHAT-34 음성 메시지
- **WHEN** 음성 메시지를 그리고 한 번 터치한다
- **THEN** 재생 아이콘 + 파형 막대 16개 + "0:05"가 보이고, 터치하면 2초 동안 재생 애니메이션이 나온다

#### Scenario: CHAT-35 입력 중 말풍선
- **WHEN** 상대가 입력 중이다
- **THEN** 맨 아래 왼쪽에 점 3개 말풍선이 보인다

#### Scenario: CHAT-36 맨 아래로
- **WHEN** 새 메시지가 오거나 채팅방을 다시 그린다
- **THEN** 항상 맨 아래 최신 메시지가 보인다

### Requirement: 24시간 메시지와 저장
메시지는 24시간 뒤 사라지되, 두 번 터치해서 저장한 메시지는 남아야 한다(SHALL).

#### Scenario: CHAT-37 저장
- **WHEN** 말풍선을 0.3초 안에 두 번 터치한다
- **THEN** 노란 테두리 + 톡 튀는 효과로 저장되고 배너 "저장했어요"가 뜬다. 한 번 더 두 번 터치하면 "저장을 해제했어요"

#### Scenario: CHAT-37b 느린 두 번
- **WHEN** 0.3초보다 천천히 두 번 터치하거나 서로 다른 말풍선을 한 번씩 터치한다
- **THEN** 저장되지 않는다

#### Scenario: CHAT-38 저장 표시 위치
- **WHEN** 저장한 메시지가 있다
- **THEN** 저장 표시는 채팅방 안에서만 보인다

#### Scenario: CHAT-39 사라지기
- **WHEN** 저장하지 않은 메시지가 24시간이 지났다
- **THEN** 다음 정리 때(15초마다) 사라지고, 저장한 메시지는 남는다

### Requirement: 메시지 보내기
채팅방 입력창은 글·사진·음성 메시지를 보낼 수 있어야 한다(SHALL).

#### Scenario: CHAT-40 입력창
- **WHEN** 채팅방을 연다
- **THEN** [사진] [입력 칸 "메시지 보내기"] [마이크] [보내기]가 보인다

#### Scenario: CHAT-41 입력 중 신호
- **WHEN** 글을 쓴다
- **THEN** 상대에게만 입력 중 신호가 가고 내 화면에는 아무것도 뜨지 않는다

#### Scenario: CHAT-42 글 보내기
- **WHEN** 글을 쓰고 보내기나 Enter(한글 조합 중 제외)를 누른다
- **THEN** 메시지가 보내지고 입력 칸이 비워진다. 공백뿐이면 보내지 않는다

#### Scenario: CHAT-42b 쓰는 중 메시지 도착
- **WHEN** 글을 쓰는 중에 상대 메시지가 온다
- **THEN** 쓰던 글과 커서가 그대로다

#### Scenario: CHAT-43 사진 보내기
- **WHEN** [사진]을 누르고 한 장을 고른다
- **THEN** 사진 메시지가 보내진다. 사진이 아니면 배너 "사진 파일만 올릴 수 있어요"

#### Scenario: CHAT-44 녹음
- **WHEN** [마이크]를 누른다
- **THEN** 입력창이 [X 취소] [빨간 점 "녹음 중 0:03"] [보내기]로 바뀌고 시간이 0.25초마다 갱신된다

#### Scenario: CHAT-44b 59초
- **WHEN** 녹음이 59초가 된다
- **THEN** 0:59 음성 메시지가 자동으로 보내진다

#### Scenario: CHAT-45 녹음 보내기와 취소
- **WHEN** 녹음 중 보내기 또는 취소를 누른다
- **THEN** 보내기는 최소 1초짜리 음성 메시지를 보내고, 취소는 아무것도 보내지 않으며, 둘 다 평소 입력창으로 돌아간다

#### Scenario: CHAT-46 녹음 중 닫기
- **WHEN** 녹음 중에 채팅방을 닫거나 다른 채팅방을 연다
- **THEN** 녹음이 취소된다

### Requirement: 시연용 상대
가짜 서버는 대화를 흉내 내서 혼자서도 채팅을 시험할 수 있게 해야 한다(SHALL).

#### Scenario: CHAT-50 첫 메시지
- **WHEN** 앱을 켜고 3.5초가 지난다
- **THEN** Teo가 "지금 오산천 쪽이야? 나 근처야!"를 보낸다

#### Scenario: CHAT-51 자동 답장
- **WHEN** 메시지를 보낸다
- **THEN** 0.9초 뒤 상대가 입력 중이 되고, 다시 1.8초 뒤 정해진 7개 중 하나로 답한다

### Requirement: 전화 화면
앱은 전화를 걸면 통화 화면을 보여줘야 한다(SHALL).

#### Scenario: CHAT-60 연결 중
- **WHEN** 채팅방에서 [전화]를 누른다
- **THEN** 그 사람 색 배경의 전체 화면에 120px 프로필, 이름, "연결 중…"이 보인다

#### Scenario: CHAT-61 통화 시간
- **WHEN** 2초가 지난다
- **THEN** "0:01, 0:02 …"처럼 통화 시간이 흐른다

#### Scenario: CHAT-62 끊기
- **WHEN** 빨간 종료 버튼을 누른다
- **THEN** 통화 화면이 닫히고 배너 "통화가 끝났어요"가 뜬다

### Requirement: 신고
앱은 신고한 사람을 친구·채팅·지도·스와이프·아이디 찾기 어디에도 다시 보여주지 않아야 한다(SHALL).

#### Scenario: CHAT-70 신고 창
- **WHEN** 채팅방에서 깃발을 누른다
- **THEN** "OO님을 신고할까요?" / "신고하면 서로의 친구, 메시지, 지도, 스와이프 목록에서 완전히 사라지고 다시 추천되지 않아요." / 이유 라디오 4개(불쾌한 메시지 · 스팸 / 광고 · 가짜 프로필 · 기타, 첫 번째 선택됨) / [취소] [신고하기(빨강)] 팝업이 뜬다

#### Scenario: CHAT-71 신고하기
- **WHEN** [신고하기]를 누른다
- **THEN** 그 사람 채팅방과 프로필 창이 닫히고 배너 "OO님을 신고했어요" / "서로의 목록에서 사라졌어요"가 뜬다

#### Scenario: CHAT-72 어디에도 안 보임
- **WHEN** 신고를 마친다
- **THEN** 그 사람은 친구, 채팅, 지도, 스와이프, 아이디 찾기에 나오지 않고 자동 답장도 오지 않으며, 나 탭 "신고한 사용자"에 이름이 보인다
