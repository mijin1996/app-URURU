# account Specification

## Purpose

처음 한 번만 가입하고 회원탈퇴 전까지 다시 묻지 않는 내 계정이에요. 아이디·닉네임·생년월일 가입, 가입 정보 유지, 나 탭의 설정 칸과 회원탈퇴를 다뤄요.

## Requirements

### Requirement: 시작 흐름
앱은 로고 화면 다음에 저장된 가입 정보가 있으면 바로 홈을, 없으면 가입 화면을 보여줘야 한다(SHALL).

#### Scenario: ACC-01 가입한 사람
- **WHEN** 저장된 가입 정보가 있는 상태로 앱을 켠다
- **THEN** 로고 화면 다음 바로 홈이 나온다

#### Scenario: ACC-01b 처음 온 사람
- **WHEN** 저장된 가입 정보가 없다
- **THEN** 로고 화면 다음 가입 화면이 나온다

#### Scenario: ACC-02 예전 형식
- **WHEN** 저장된 가입 정보에 아이디가 없다
- **THEN** 가입 정보가 없는 것으로 보고 가입 화면을 보여준다

#### Scenario: ACC-03 가입 직후
- **WHEN** 가입을 마친다
- **THEN** 홈으로 가고, 0.7초 뒤 아직 답하지 않은 사람에게만 무음 소리 받기 묻기 창을 띄운다

### Requirement: 가입 화면 구성
가입 화면은 정해진 순서와 문구로 아이디·닉네임·생년월일 칸을 보여줘야 한다(SHALL).

#### Scenario: ACC-10 순서
- **WHEN** 가입 화면을 그린다
- **THEN** 위에서부터 "우르르" 로고(44px), "처음 오셨네요!", 아이디 칸, 아이디 검사 문구, 닉네임 칸, 생년월일 칸, 오류 문구, "시작하기" 버튼이고, 모두 화면 가로 가운데에 맞춰 놓인다. 칸 이름·검사 문구·오류 문구는 입력 칸 왼쪽 테두리에 맞춰 왼쪽 정렬이다

#### Scenario: ACC-11 안내 문단 없음
- **WHEN** 가입 화면을 그린다
- **THEN** "처음 오셨네요!" 아래에 안내 문단 없이 바로 아이디 칸이 나온다

#### Scenario: ACC-12 아이디 칸
- **WHEN** 아이디 칸을 그린다
- **THEN** 이름은 "아이디 · 영어와 숫자만", 예시 글은 "예: ururu123", 최대 15자이고 자동 대문자·맞춤법 검사가 꺼져 있다

### Requirement: 아이디 규칙과 바로 검사
앱은 아이디를 앞뒤 공백을 지우고 소문자로 바꾼 뒤 영어 소문자·숫자 4~15자, 중복 없음 규칙으로 검사하고, 쓰는 동안 결과를 바로 보여줘야 한다(SHALL).

#### Scenario: ACC-13 사용 가능
- **WHEN** 규칙에 맞고 아무도 안 쓰는 아이디를 쓴다
- **THEN** 초록 글씨로 "'mimi2026' 사용할 수 있는 아이디예요"가 보인다

#### Scenario: ACC-13b 칸 비우기
- **WHEN** 아이디 칸을 다시 비운다
- **THEN** 검사 문구도 사라진다

#### Scenario: ACC-14 대문자 입력
- **WHEN** "Teo24"를 쓴다
- **THEN** "teo24"로 바꿔 검사해서 빨간 글씨 "'teo24'은(는) 이미 존재하는 아이디예요. 다른 아이디를 써주세요"가 보인다

#### Scenario: ACC-14b 허용 안 되는 글자
- **WHEN** 한글이나 기호가 들어간 아이디를 쓴다
- **THEN** "아이디는 영어 알파벳과 숫자만 쓸 수 있어요"가 보인다

#### Scenario: ACC-14c 길이
- **WHEN** 3자 이하 아이디를 쓴다
- **THEN** "아이디는 4~15자로 만들어 주세요"가 보인다

### Requirement: 닉네임과 생년월일 검사
앱은 닉네임을 앞뒤 공백을 지운 1~12자로, 생년월일을 만 19세 이상인 올바른 날짜로 받아야 한다(SHALL). (2026-10-13 미미: 모든 빌드 만 19세)

#### Scenario: ACC-15 닉네임
- **WHEN** 닉네임을 쓴다
- **THEN** 최대 12자까지 써지고 다른 사람과 같아도 된다

#### Scenario: ACC-19 생년월일 없음
- **WHEN** 생년월일을 고르지 않고 시작한다
- **THEN** "생년월일을 골라주세요"가 보인다

#### Scenario: ACC-19b 만 19세 미만
- **WHEN** 내일이 만 19세 생일인 날짜를 고른다
- **THEN** "만 19세 이상부터 가입할 수 있어요"가 보인다

#### Scenario: ACC-19c 오늘 생일
- **WHEN** 오늘이 만 19세 생일인 날짜를 고른다
- **THEN** 가입할 수 있다

### Requirement: 가입하기
앱은 구글 버튼을 누르면 아이디, 닉네임, 생년월일, 국가 순서로 검사해 첫 번째 실패 이유만 보여주고, 모두 맞으면 저장한 뒤 홈으로 가야 한다(SHALL).

#### Scenario: ACC-18 첫 실패 이유
- **WHEN** 아이디와 닉네임이 둘 다 틀린 채 구글 버튼을 누른다
- **THEN** 아이디 실패 이유만 빨간 글씨로 보인다

#### Scenario: ACC-18b Enter
- **WHEN** 한글 조합 중이 아닌 상태에서 Enter를 누른다
- **THEN** 구글 버튼을 누른 것과 같다

#### Scenario: ACC-18c 한글 조합 중 Enter
- **WHEN** 한글을 조합하는 중에 Enter를 누른다
- **THEN** 가입 검사를 하지 않는다

### Requirement: 생년월일 달력
앱은 아이폰처럼 년·월·일 바퀴를 굴려서 생년월일을 고르게 해야 한다(SHALL).

#### Scenario: ACC-16 칸 모양
- **WHEN** 아직 고르지 않았다
- **THEN** 화살표 없이 빈칸이고, 누르면 돌림판이 열리며, 고르면 "2001년 3월 15일"처럼 진한 글자로 바뀐다

#### Scenario: ACC-17 처음 날짜
- **WHEN** 달력을 처음 연다
- **THEN** 2000년 1월 1일에서 시작하고, 한 번 고른 뒤에는 고른 날짜에서 시작한다

#### Scenario: ACC-30 바퀴 굴리기
- **WHEN** 아래에서 올라온 창에서 바퀴를 굴리고 손을 뗀다
- **THEN** 가운데 줄에 한 칸(36px)씩 딱 멈춘다

#### Scenario: ACC-32 년도 범위
- **WHEN** 년 바퀴를 끝까지 굴린다
- **THEN** 1940년부터 올해까지만 있다

#### Scenario: ACC-33 달마다 날짜 수
- **WHEN** 2월 29일을 고른 뒤 년도를 평년으로 바꾼다
- **THEN** 일 바퀴가 28일까지로 바뀌고 28일이 선택된다

#### Scenario: ACC-34 완료와 취소
- **WHEN** 위쪽 줄 [취소] "생년월일" [완료] 중 버튼을 누른다
- **THEN** "완료"는 고른 날짜를 칸에 넣고 닫히며, "취소"는 그냥 닫힌다

### Requirement: 가입 정보 유지
앱은 가입 정보(아이디, 닉네임, 생년월일, 소리 받기 권한)를 저장해서 회원탈퇴 전까지 다시 가입을 묻지 않아야 한다(SHALL).

#### Scenario: ACC-40 다시 열기
- **WHEN** 가입한 뒤 앱을 닫았다가 다시 연다
- **THEN** 가입 화면 없이 홈이 나온다

#### Scenario: ACC-41 바로 저장
- **WHEN** 닉네임이나 소리 받기 권한을 바꾼다
- **THEN** 바로 저장되어 다시 열어도 유지된다

#### Scenario: ACC-42 저장소를 못 쓸 때
- **WHEN** 저장소를 쓸 수 없는 환경(시크릿 창 등)이다
- **THEN** 오류 없이 앱을 켜 둔 동안만 기억한다

### Requirement: 나 탭 설정
나 탭은 설정 3줄과 신고한 사용자 목록을 보여줘야 하고, 위치 공유는 이 설정에서만 켜고 꺼야 한다(SHALL).

#### Scenario: ACC-50 설정 줄 모양
- **WHEN** 설정 상자를 그린다
- **THEN** 한 줄마다 제목과 작은 토글(34×20px)만 있고 설명 글은 없다

#### Scenario: ACC-51 위치 공유
- **WHEN** "친구와 위치 공유" 토글을 누른다
- **THEN** 켜면 친구들 지도에 내가 보이고, 끄면 친구 지도에서 숨겨지고 내 핀이 회색이 된다 (배너 없음)

#### Scenario: ACC-51c 위치를 끈 빌드
- **WHEN** `canShareLocation`을 끈 빌드에서 나 탭 설정을 본다
- **THEN** "친구와 위치 공유" 줄이 없고 나머지 설정 줄만 보인다

#### Scenario: ACC-51b 다시 열면
- **WHEN** 위치 공유를 끈 뒤 앱을 다시 연다
- **THEN** (시제품 한계) 켜진 상태로 시작한다

#### Scenario: ACC-52 메시지 알림음
- **WHEN** "메시지 알림음"을 끈다
- **THEN** 새 메시지가 와도 알림음이 나지 않는다

#### Scenario: ACC-53 무음 소리 받기
- **WHEN** "무음에서도 소리 받기" 토글을 누른다
- **THEN** 토글이 바로 바뀌지 않고 휴대폰 설정 안내 창이 열린다

#### Scenario: ACC-54 톡 소리
- **WHEN** 위치 공유나 알림음 토글을 누른다
- **THEN** 켤 때는 높은 "톡", 끌 때는 낮은 "톡" 소리가 난다

#### Scenario: ACC-55 신고한 사용자
- **WHEN** "신고한 사용자" 상자를 그린다
- **THEN** 신고한 사람 이름이 쉼표로 이어져 보이고, 없으면 "아직 없어요."다

### Requirement: 회원탈퇴
앱은 확인을 받은 뒤에만 계정과 가입 정보를 지우고 처음부터 다시 시작해야 한다(SHALL).

#### Scenario: ACC-60 버튼
- **WHEN** 나 탭 맨 아래를 본다
- **THEN** 글자 길이만큼의 회색 "회원탈퇴" 글자 버튼이 있다

#### Scenario: ACC-61 확인 창
- **WHEN** "회원탈퇴"를 누른다
- **THEN** "정말 탈퇴할까요?" / "아이디, 사진, 스토리, 친구 목록이 모두 지워지고 되돌릴 수 없어요." / [취소] [탈퇴하기(빨강)] 팝업이 뜬다

#### Scenario: ACC-62 취소
- **WHEN** 바깥이나 "취소"를 누른다
- **THEN** 팝업만 닫힌다

#### Scenario: ACC-63 탈퇴하기
- **WHEN** "탈퇴하기"를 누른다
- **THEN** 서버 계정과 저장된 가입 정보가 지워지고 로고 → 가입 화면부터 다시 시작한다

### Requirement: 서버 계정
서버 모드에서 가입 정보는 서버 계정에 저장되어 다른 기기에서도 같은 계정으로 쓸 수 있어야 한다(SHALL).

#### Scenario: ACC-S1 로그인 먼저
- **WHEN** 서버 모드에서 처음 앱을 연다
- **THEN** 로고 다음 빌드에 맞는 방법으로 로그인하고(구글 로그인), 아직 아이디가 없는 사람에게만 가입 화면(아이디·닉네임·생년월일)이 나온다

#### Scenario: ACC-S1b 로그인 실패
- **WHEN** 서버 모드에서 인터넷이 끊겨 로그인하지 못했다
- **THEN** 가입 화면 대신 이유를 배너로 보여주고 잠시 뒤 다시 시도한다

#### Scenario: ACC-S2 다른 기기
- **WHEN** 같은 계정으로 다른 기기에서 로그인한다
- **THEN** 가입 화면 없이 같은 아이디·닉네임·친구·대화가 보인다

#### Scenario: ACC-S3 아이디 중복 (서버)
- **WHEN** 다른 사용자가 이미 쓰는 아이디로 가입하려 한다
- **THEN** 전체 사용자 기준으로 "이미 존재하는 아이디예요"가 뜬다

#### Scenario: ACC-S4 회원탈퇴 (서버)
- **WHEN** 서버 모드에서 회원탈퇴를 한다
- **THEN** 서버의 계정, 프로필, 사진, 메시지, 스토리, 좋아요, 위치가 모두 지워지고 아이디는 다시 쓸 수 있게 된다

### Requirement: 약관 동의
가입할 때 이용약관과 개인정보처리방침에 동의해야만 가입할 수 있어야 한다(SHALL).

#### Scenario: SAFE-10 동의 안 함
- **WHEN** 약관 동의 칸을 체크하지 않고 구글 버튼을 누른다
- **THEN** "이용약관과 개인정보처리방침에 동의해 주세요"가 뜨고 가입되지 않는다

#### Scenario: SAFE-11 약관 보기
- **WHEN** 동의 칸 옆 "보기"를 누른다
- **THEN** 이용약관(금지 행동 포함)과 개인정보처리방침이 열린다

### Requirement: 앱 밖 회원탈퇴
앱을 지운 사람도 문의 이메일(unidevpeer@gmail.com)로 회원탈퇴와 데이터 삭제를 요청할 수 있어야 한다(SHALL). (구글 플레이 출시 때는 웹 페이지를 따로 만든다)

#### Scenario: SAFE-12 이메일로 탈퇴
- **WHEN** 아이디를 적어 문의 이메일로 탈퇴를 요청한다
- **THEN** 운영자가 7일 안에 서버 함수 deleteAccount와 같은 방법으로 계정과 데이터를 지운다

### Requirement: 로그아웃
앱은 계정을 지우지 않고 이 기기에서만 나갈 수 있게 해야 한다(SHALL).

#### Scenario: ACC-64 버튼
- **WHEN** 나 탭 맨 아래를 본다
- **THEN** "회원탈퇴" 바로 위에 같은 모양의 회색 "로그아웃" 글자 버튼이 있다

#### Scenario: ACC-65 로그아웃하기
- **WHEN** "로그아웃"을 누른다
- **THEN** 확인 창 없이 로그아웃되고, 이 기기의 가입 정보만 지워진 뒤 로고 → 가입 화면부터 다시 시작한다

#### Scenario: ACC-66 다시 로그인
- **WHEN** 로그아웃한 뒤 같은 구글 계정으로 다시 로그인한다
- **THEN** 서버에 있는 가입 정보 그대로 들어간다

### Requirement: 다시 로그인할 때 구글 버튼만
앱은 이 기기에서 가입한 적 있는 사람에게 가입 칸을 다시 채우게 하지 않아야 한다(SHALL).

#### Scenario: ACC-67 구글 버튼만
- **WHEN** 이 기기에서 가입한 뒤 로그아웃하고 다시 가입 화면을 본다
- **THEN** 로고와 구글 버튼만 보이고 아이디 · 닉네임 · 생년월일 · 국가 칸은 없다

#### Scenario: ACC-68 가입 안 된 구글 계정
- **WHEN** 구글 버튼만 있는 화면에서 아직 가입하지 않은 구글 계정으로 들어간다
- **THEN** 그때 네 칸이 나타나고, 채운 뒤 구글 버튼을 누르면 가입된다

#### Scenario: ACC-69 다른 기기에서 가입한 사람
- **WHEN** 칸을 하나도 채우지 않고 구글 버튼을 눌렀는데 그 계정이 이미 가입돼 있다
- **THEN** 칸 없이 바로 시작한다
