# swipe Specification

## Purpose

주변 사람을 카드로 한 명씩 보고 하트(좋아요) 또는 X(넘기기)를 고르는 스와이프예요. 1시간에 5명까지 볼 수 있고, X 한 사람은 1시간 뒤 다시 나와요.

## Requirements

### Requirement: 스와이프 화면
스와이프 탭은 남은 수, 카드 더미, X와 하트 버튼을 보여줘야 한다(SHALL).

#### Scenario: SWP-01 고정 화면
- **WHEN** 스와이프 탭을 연다
- **THEN** 제목 "스와이프"가 보이고 화면은 스크롤되지 않는다

#### Scenario: SWP-02 남은 수
- **WHEN** 이번 1시간에 2명을 봤다
- **THEN** 제목 아래 "이번 1시간에 3 / 5명 더 볼 수 있어요"가 보인다

#### Scenario: SWP-03 카드 더미
- **WHEN** 볼 사람이 여러 명이다
- **THEN** 맨 위 카드와 뒤에 살짝 보이는 카드 1장이 있다. 남은 수가 1이면 1장만 있다

#### Scenario: SWP-04 카드 내용
- **WHEN** 카드를 그린다
- **THEN** 대표 사진, 아래 어둡게, 처음엔 안 보이는 "좋아요"·"넘기기" 도장, 이름 + 나이 + 초록 점, "➤ 1.2km · 동네", 관심사 칩, "눌러서 사진 3장 보기"가 있다

#### Scenario: SWP-05 버튼
- **WHEN** 카드가 있다
- **THEN** 카드 아래 동그란 [X] [하트] 버튼이 있다

### Requirement: 보여줄 사람
스와이프는 친구가 아니고, 내가 좋아요를 보낸 적 없고, 최근 1시간 안에 X 하지 않았고, 신고하지 않은 사람만 보여줘야 한다(SHALL).

#### Scenario: SWP-10 걸러내기
- **WHEN** 카드 더미를 만든다
- **THEN** 친구, 좋아요 보낸 사람, 1시간 안에 X 한 사람, 신고한 사람은 나오지 않는다

#### Scenario: SWP-11 1시간 뒤
- **WHEN** X 한 지 1시간이 지난다
- **THEN** 그 사람이 다시 나온다

### Requirement: 끌기와 누르기
스와이프 카드는 끌어서 넘기거나, 버튼으로 넘기거나, 터치해서 프로필을 열 수 있어야 한다(SHALL).

#### Scenario: SWP-20 끄는 중
- **WHEN** 카드를 오른쪽으로 끈다
- **THEN** 카드가 따라 움직이고 기울어지며 "좋아요" 도장이 점점 진해진다 (왼쪽은 "넘기기")

#### Scenario: SWP-21 넘기기
- **WHEN** 100px 넘게 끌고 놓는다
- **THEN** 카드가 그쪽으로 날아가고 오른쪽이면 좋아요, 왼쪽이면 넘기기가 된다

#### Scenario: SWP-22 제자리
- **WHEN** 6px 이상 100px 이하로 끌고 놓는다
- **THEN** 카드가 0.25초 동안 제자리로 돌아오고 도장이 사라진다

#### Scenario: SWP-23 터치
- **WHEN** 거의 움직이지 않고(6px 미만) 놓는다
- **THEN** 그 사람 프로필이 커지는 느낌으로 열린다

#### Scenario: SWP-24 하트
- **WHEN** 하트 버튼을 누른다
- **THEN** 그 순간 하트가 꽉 찬 하트로 바뀌고, 카드가 날아가며, 0.35초 뒤 좋아요가 보내진다

#### Scenario: SWP-25 X
- **WHEN** X 버튼을 누른다
- **THEN** 카드가 날아가고 0.35초 뒤 넘기기가 된다

#### Scenario: SWP-26 셈
- **WHEN** 좋아요나 X를 한다
- **THEN** 한 명 본 것으로 센다

#### Scenario: SWP-27 빠르게 두 번
- **WHEN** 하트를 빠르게 두 번 누른다
- **THEN** 한 명만 처리된다

#### Scenario: SWP-28 끄는 중 데이터 변경
- **WHEN** 카드를 끄는 도중 서버 소식으로 데이터가 바뀐다
- **THEN** 카드가 튀거나 처음 위치로 돌아가지 않는다

### Requirement: 좋아요와 넘기기 결과
스와이프는 좋아요 결과를 알리고, 넘긴 사람에게는 아무것도 보내지 않아야 한다(SHALL).

#### Scenario: SWP-30 서로 좋아요
- **WHEN** 나를 이미 좋아한 사람에게 좋아요를 보낸다
- **THEN** 바로 친구가 되고 배너 "서로 좋아요! OO님과 친구가 됐어요" / "눌러서 대화 시작하기"(누르면 채팅방)가 뜨며 상대가 인사 메시지를 보낸다

#### Scenario: SWP-31 좋아요 보냄
- **WHEN** 그 밖의 사람에게 좋아요를 보낸다
- **THEN** 배너 "OO님에게 좋아요를 보냈어요" / "상대가 '친구할까요?'를 누르면 친구가 돼요"가 뜨고 상대 친구 탭에 내 좋아요가 뜬다

#### Scenario: SWP-32 수락 (시연)
- **WHEN** 좋아요를 보내고 4초가 지난다
- **THEN** 상대가 수락해서 "OO님과 친구가 됐어요" 배너와 인사 메시지가 온다. 그새 신고했거나 X 했으면 수락하지 않는다

#### Scenario: SWP-33 X
- **WHEN** X를 한다
- **THEN** 상대에게 아무것도 가지 않고, 그 사람이 나에게 보낸 좋아요는 내 친구 탭 목록에서 빠진다

### Requirement: 다 봤을 때
스와이프는 볼 사람이 없으면 이유와 다시 볼 수 있는 때를 알려주고, 그때가 되면 저절로 다시 그려야 한다(SHALL).

#### Scenario: SWP-40 버튼 숨김
- **WHEN** 볼 카드가 없다
- **THEN** 카드 자리에 안내 2줄이 보이고 X와 하트 버튼이 사라진다

#### Scenario: SWP-41 5명 다 봄
- **WHEN** 이번 1시간에 5명을 다 봤다
- **THEN** "1시간에 5명까지 볼 수 있어요."와 "n분 뒤에 다시 볼 수 있어요."가 보인다. n분은 가장 먼저 본 한 명이 1시간을 채우는 때까지, 최소 1분, 올림이다

#### Scenario: SWP-42 사람 없음
- **WHEN** 남은 수는 있지만 볼 사람이 없고 X 한 사람이 있다
- **THEN** "프로필을 다 봤어요."와 X 한 사람 중 가장 먼저 돌아오는 때까지의 "n분 뒤에 다시 볼 수 있어요."가 보인다

#### Scenario: SWP-42b 기다릴 사람도 없음
- **WHEN** 볼 사람도 X 한 사람도 없다
- **THEN** "프로필을 다 봤어요."와 "새로운 사람이 생기면 보여드릴게요."가 보인다

#### Scenario: SWP-44 저절로 다시 그리기
- **WHEN** 스와이프 탭을 보고 있는 중에 다시 볼 수 있는 시각이 된다
- **THEN** 화면이 저절로 다시 그려진다

#### Scenario: SWP-45 다시 열면
- **WHEN** 앱을 다시 연다
- **THEN** (시제품 한계) 남은 수가 5명부터 다시 시작한다
