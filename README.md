# 우르르 (Ururu)

> **한 줄 요약** 가까운 친구와 가볍게 모이는 위치 기반 채팅 앱이에요. React 19 + Firebase, 구글 플레이 출시 준비 중.

## 빠른 시작

```bash
npm install
npm run dev      # http://localhost:5173
npm run test     # 시험
```

처음이면 [docs/tutorials/getting-started.md](docs/tutorials/getting-started.md)를 따라 하세요.
